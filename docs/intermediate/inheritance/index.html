Inheritance & Dunder Methods

In this module you will learn how Python's inheritance system lets classes share and extend behaviour, and how dunder (double-underscore) methods let you integrate your objects seamlessly into the Python language — making them printable, comparable, and iterable. By the end you will be able to design clean class hierarchies and write Pythonic objects that work naturally with built-in functions and operators.

Learning Objectives​

  • Use super() to call parent class methods
  • Set up single and multiple inheritance
  • Understand Python's Method Resolution Order (MRO)
  • Implement __str__ and __repr__ for readable output
  • Use __eq__, __lt__, and other comparison dunders
  • Overload operators with __add__, __mul__, etc.
  • Make objects work with len() and indexing via __len__ and __getitem__

Theory​

super() and Single Inheritance​

super() gives you a proxy that delegates method calls to the parent class, ensuring proper initialisation chains:

class Animal:
    def __init__(self, name, sound):
        self.name = name
        self.sound = sound

    def speak(self):
        return f"{self.name} says {self.sound}"

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name, sound="Woof")  # call parent __init__
        self.breed = breed

    def fetch(self):
        return f"{self.name} fetches the ball!"

d = Dog("Rex", "Labrador")
print(d.speak())   # Rex says Woof
print(d.fetch())   # Rex fetches the ball!
tip

Always call super().__init__() in your subclass __init__ when the parent has state to initialise. Forgetting it leaves parent attributes undefined.

See Inheritance in the Python Tutorial.

Multiple Inheritance and MRO​

Python supports multiple inheritance. The Method Resolution Order (MRO) defines which class is searched first when looking up an attribute:

class A:
    def hello(self):
        return "Hello from A"

class B(A):
    def hello(self):
        return "Hello from B"

class C(A):
    def hello(self):
        return "Hello from C"

class D(B, C):    # inherits from both B and C
    pass

print(D().hello())       # Hello from B  (B comes before C in MRO)
print(D.__mro__)         # (D, B, C, A, object)

Python uses the C3 linearisation algorithm to compute the MRO. The __mro__ attribute and ClassName.mro() method let you inspect it.

note

Multiple inheritance is powerful but can make code hard to follow. Use it deliberately — common patterns include mixins (small classes that add a single behaviour).

See Multiple Inheritance.

__str__ and __repr__​

  • __str__ is called by str() and print() — intended for human-readable output.
  • __repr__ is called by repr() and is the fallback when __str__ is not defined — intended for developers and debugging. A good __repr__ should produce a string that makes it easy to reconstruct the object.
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

    def __str__(self):
        return f"({self.x}, {self.y})"

p = Point(3, 4)
print(str(p))    # (3, 4)
print(repr(p))   # Point(3, 4)
tip

Implement __repr__ first — it is more important for debugging. __str__ defaults to __repr__ when not explicitly defined.

Comparison Dunder Methods​

Implement these to support comparison operators:

DunderOperator
__eq__==
__ne__!=
__lt__<
__le__<=
__gt__>
__ge__>=
from functools import total_ordering

@total_ordering
class Version:
    def __init__(self, major, minor):
        self.major, self.minor = major, minor

    def __eq__(self, other):
        return (self.major, self.minor) == (other.major, other.minor)

    def __lt__(self, other):
        return (self.major, self.minor) < (other.major, other.minor)

@total_ordering fills in the remaining comparison methods from just __eq__ and __lt__. See functools.total_ordering.

__len__ and __getitem__​

These make objects work with len() and bracket indexing obj[i]:

class Playlist:
    def __init__(self):
        self._songs = []

    def add(self, song):
        self._songs.append(song)

    def __len__(self):
        return len(self._songs)

    def __getitem__(self, index):
        return self._songs[index]

pl = Playlist()
pl.add("Song A"); pl.add("Song B")
print(len(pl))    # 2
print(pl[0])      # Song A

See Data Model — Special Method Names for the complete reference.

Operator Overloading​

class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, scalar):
        return Vector(self.x * scalar, self.y * scalar)

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)      # Vector(4, 6)
print(v1 * 3)       # Vector(3, 6)
