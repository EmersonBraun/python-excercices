# Classes & Objects

In this module you will learn how Python implements **Object-Oriented Programming** (OOP) through classes, instances, and methods. You will define classes with `__init__`, manage instance and class variables, use `self`, and expose safe attribute access with `@property`. By the end you will be able to model real-world entities as Python classes.

## Learning Objectives

- Define a class and instantiate objects
- Write `__init__` to initialise instance attributes
- Distinguish instance methods, class methods, and static methods
- Understand the difference between instance variables and class variables
- Use `@property` and setters to encapsulate attribute access

---

## Theory

### Defining a Class

A class is a blueprint for objects. You define one with the `class` keyword:

```python
class Dog:
    species = "Canis familiaris"   # class variable — shared by all instances

    def __init__(self, name, age):
        self.name = name           # instance variable — unique per object
        self.age = age

    def bark(self):
        return f"{self.name} says: Woof!"

rex = Dog("Rex", 3)
print(rex.bark())            # Rex says: Woof!
print(rex.species)           # Canis familiaris
print(Dog.species)           # Canis familiaris
```

:::tip
Use `ClassName` in `PascalCase` (also called `UpperCamelCase`). Instances and methods use `snake_case`.
:::

See [Classes — Python Tutorial](https://docs.python.org/3/tutorial/classes.html).

### `__init__` and `self`

`__init__` is the **initialiser** (informally called the constructor). It is called automatically when you create a new instance. The first parameter (`self`) is a reference to the newly created object:

```python
class Circle:
    PI = 3.14159

    def __init__(self, radius):
        if radius <= 0:
            raise ValueError("Radius must be positive")
        self.radius = radius

    def area(self):
        return Circle.PI * self.radius ** 2

    def perimeter(self):
        return 2 * Circle.PI * self.radius
```

:::note
`self` is just a naming convention — Python passes the instance as the first argument automatically. Any other name works, but `self` is the universal standard.
:::

### Instance vs. Class Variables

| | Instance variable | Class variable |
|-|-------------------|----------------|
| Defined in | `__init__` (usually) | Class body (outside methods) |
| Stored on | The instance | The class |
| Scope | Unique to each object | Shared across all instances |

```python
class Counter:
    count = 0          # class variable

    def __init__(self):
        Counter.count += 1
        self.id = Counter.count   # instance variable

a = Counter()
b = Counter()
print(Counter.count)  # 2
print(a.id, b.id)     # 1 2
```

### `@property`

`@property` turns a method into a read-only attribute, letting you add validation or computed values without changing the external interface:

```python
class Temperature:
    def __init__(self, celsius):
        self._celsius = celsius

    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("Temperature below absolute zero!")
        self._celsius = value

    @property
    def fahrenheit(self):
        return self._celsius * 9 / 5 + 32

t = Temperature(100)
print(t.fahrenheit)   # 212.0
t.celsius = 0
print(t.fahrenheit)   # 32.0
```

:::tip
Prefix "private" attributes with a single underscore (`_celsius`) by convention. Python doesn't enforce access control but the underscore signals "don't touch this directly".
:::

See [property — Built-in Functions](https://docs.python.org/3/library/functions.html#property).

### `@classmethod` and `@staticmethod`

```python
class Date:
    def __init__(self, year, month, day):
        self.year, self.month, self.day = year, month, day

    @classmethod
    def from_string(cls, date_str):
        year, month, day = map(int, date_str.split("-"))
        return cls(year, month, day)   # creates an instance

    @staticmethod
    def is_leap_year(year):
        return year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)

d = Date.from_string("2024-03-15")
print(Date.is_leap_year(2024))  # True
```
