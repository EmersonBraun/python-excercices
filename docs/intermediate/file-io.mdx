# File I/O

In this module you will learn how Python reads and writes files using the built-in `open()` function, handles CSV and JSON data, and safely manages resources with the **context manager** (`with` statement). By the end you will be confident reading, writing, and transforming file-based data in Python.

## Learning Objectives

- Open files in different modes (`r`, `w`, `a`, `rb`)
- Read and write text files safely with context managers
- Parse and write CSV data using the `csv` module
- Serialize and deserialize JSON with the `json` module
- Use `io.StringIO` for in-memory file-like objects (Pyodide-friendly)

---

## Theory

### The `open()` Function and File Modes

Python opens files with the built-in `open()` function. The second argument is the **mode**:

| Mode | Meaning |
|------|---------|
| `"r"` | Read (default) — file must exist |
| `"w"` | Write — creates or **overwrites** the file |
| `"a"` | Append — creates or **adds to** the end |
| `"rb"` / `"wb"` | Binary read / write |

```python
f = open("data.txt", "w")
f.write("Hello, file!")
f.close()           # always close when done
```

:::tip
Forgetting to call `close()` can corrupt files or leak file descriptors. Use the `with` statement (see below) instead — it closes the file automatically.
:::

See [open() — Built-in Functions](https://docs.python.org/3/library/functions.html#open) for a full reference.

### Context Managers — `with` Statement

The `with` statement guarantees that the file is closed when the block exits, even if an exception occurs:

```python
with open("data.txt", "w") as f:
    f.write("Hello, file!\n")
    f.write("Second line.\n")
# file is automatically closed here
```

Reading back the file:

```python
with open("data.txt", "r") as f:
    content = f.read()          # entire file as a string
    # — or —
    lines = f.readlines()       # list of lines
    # — or —
    for line in f:              # iterate line-by-line
        print(line.strip())
```

:::note
In Pyodide (the in-browser Python runtime used here) you can write to the virtual filesystem just like on a real machine. The files only live for the duration of the page session.
:::

See [Reading and Writing Files](https://docs.python.org/3/tutorial/inputoutput.html#reading-and-writing-files) for more detail.

### `io.StringIO` — In-Memory Files

`io.StringIO` gives you a file-like object backed by a string in memory. It is useful for testing code that expects a file without touching the disk:

```python
import io

buffer = io.StringIO()
buffer.write("line one\n")
buffer.write("line two\n")
buffer.seek(0)               # rewind to the start
content = buffer.read()
print(content)
```

See [io — Core tools for working with streams](https://docs.python.org/3/library/io.html).

### CSV Handling

The `csv` module makes reading and writing comma-separated values straightforward:

```python
import csv, io

# Write CSV to a StringIO buffer
output = io.StringIO()
writer = csv.writer(output)
writer.writerow(["name", "age", "city"])
writer.writerow(["Alice", 30, "London"])
writer.writerow(["Bob", 25, "Paris"])

# Read it back
output.seek(0)
reader = csv.DictReader(output)
for row in reader:
    print(row["name"], row["age"])
```

:::tip
Use `csv.DictReader` to get each row as a dictionary keyed by the header names — far more readable than indexing by column number.
:::

See [csv — CSV File Reading and Writing](https://docs.python.org/3/library/csv.html).

### JSON Handling

The `json` module converts Python objects to JSON strings and back:

```python
import json

data = {"name": "Alice", "scores": [95, 87, 92], "active": True}

# Serialize Python → JSON string
json_str = json.dumps(data, indent=2)
print(json_str)

# Deserialize JSON string → Python
loaded = json.loads(json_str)
print(loaded["name"])        # Alice
print(loaded["scores"][0])   # 95
```

Use `json.dump()` / `json.load()` when working with actual file objects instead of strings.

See [json — JSON encoder and decoder](https://docs.python.org/3/library/json.html).
