# Loops & Iteration

Loops let you repeat a block of code without copy-pasting it. In this module you will learn Python's two loop constructs — `for` and `while` — along with the tools that make iteration more expressive: `range()`, `enumerate()`, `break`, `continue`, and nested loops.

## Learning Objectives

- Write `for` loops over sequences and `range()` objects
- Write `while` loops with correct termination conditions
- Use `break` to exit a loop early and `continue` to skip an iteration
- Use `enumerate()` to loop with an index
- Build nested loops for multi-dimensional problems

---

## Theory

### for Loops

A `for` loop iterates over any **iterable** — a list, string, tuple, range, etc.:

```python
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

for char in "Python":
    print(char)
```

:::tip
The loop variable (`fruit`, `char`) is just a regular variable. You can name it anything, but pick something meaningful.
:::

### range()

`range()` generates a sequence of integers without storing them all in memory:

```python
range(5)          # 0, 1, 2, 3, 4
range(1, 6)       # 1, 2, 3, 4, 5
range(0, 10, 2)   # 0, 2, 4, 6, 8  (step of 2)
range(10, 0, -1)  # 10, 9, ..., 1  (count down)
```

See [range()](https://docs.python.org/3/library/stdtypes.html#ranges) in the docs.

### while Loops

A `while` loop repeats as long as its condition is `True`:

```python
count = 0
while count < 5:
    print(count)
    count += 1
```

:::note
Always make sure the loop condition will eventually become `False`, otherwise you create an **infinite loop**.
:::

### break and continue

- `break` — immediately exits the enclosing loop
- `continue` — skips the rest of the current iteration and jumps to the next one

```python
for n in range(10):
    if n == 5:
        break       # stop when n reaches 5
    if n % 2 == 0:
        continue    # skip even numbers
    print(n)        # prints 1, 3
```

See [break and continue](https://docs.python.org/3/tutorial/controlflow.html#break-and-continue-statements) in the tutorial.

### enumerate()

When you need both the index and the value during a loop, use `enumerate()`:

```python
colors = ["red", "green", "blue"]
for i, color in enumerate(colors):
    print(f"{i}: {color}")
# 0: red
# 1: green
# 2: blue

# Start counting from 1:
for i, color in enumerate(colors, start=1):
    print(f"{i}. {color}")
```

### Nested Loops

You can place a loop inside another loop. The inner loop completes all its iterations for each single iteration of the outer loop:

```python
for row in range(3):
    for col in range(3):
        print(f"({row},{col})", end=" ")
    print()   # newline after each row
```

:::tip
Watch out for performance: if both loops run `n` times, the body executes `n²` times.
:::

See the [Python Tutorial — for Statements](https://docs.python.org/3/tutorial/controlflow.html#for-statements) for more.
