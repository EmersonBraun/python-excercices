Dictionaries, Sets & Comprehensions

Dictionaries and sets are Python's primary unordered collection types. Dictionaries map keys to values and are everywhere in real-world Python code. Sets store unique elements and support fast membership testing and mathematical set operations. In this module you will also master dict and set comprehensions for concise, expressive code.

Learning Objectives​

  • Create, access, and modify dictionaries
  • Use common dict methods (.get(), .keys(), .values(), .items(), .update(), .pop())
  • Create sets and perform union, intersection, and difference operations
  • Write dict and set comprehensions
  • Work with nested dictionaries

Theory​

Dictionary Basics​

A dictionary is an ordered (Python 3.7+) mapping of unique keys to values, enclosed in curly braces:

person = {"name": "Alice", "age": 30, "city": "NYC"}
empty  = {}

Access values by key. Missing keys raise KeyError — use .get() to provide a default:

person["name"]              # "Alice"
person.get("email")         # None    (key missing, no error)
person.get("email", "N/A")  # "N/A"  (explicit default)

Add, update, and delete entries:

person["email"] = "alice@example.com"   # add
person["age"] = 31                       # update
del person["city"]                       # delete
popped = person.pop("email")             # remove and return

Dictionary Methods​

d = {"a": 1, "b": 2, "c": 3}

d.keys()           # dict_keys(["a", "b", "c"])
d.values()         # dict_values([1, 2, 3])
d.items()          # dict_items([("a", 1), ("b", 2), ("c", 3)])

d.update({"d": 4, "a": 10})  # merge another dict (overrides existing keys)
d.setdefault("e", 0)          # insert key with default if not present

# Iterate:
for key, value in d.items():
    print(f"{key} -> {value}")

See Dictionaries in the docs.

Dict Comprehensions​

squares = {x: x**2 for x in range(1, 6)}
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Filter with a condition:
even_squares = {x: x**2 for x in range(10) if x % 2 == 0}

# Invert a dictionary:
original = {"a": 1, "b": 2, "c": 3}
inverted = {v: k for k, v in original.items()}
# {1: "a", 2: "b", 3: "c"}

Set Basics​

A set is an unordered collection of unique items, also enclosed in curly braces:

fruits = {"apple", "banana", "cherry", "apple"}  # "apple" stored once
empty_set = set()   # NOT {} — that creates an empty dict!
fruits.add("mango")         # add one element
fruits.remove("banana")     # remove (raises KeyError if missing)
fruits.discard("banana")    # remove (no error if missing)
"cherry" in fruits          # True — O(1) membership test
tip

Use a set instead of a list whenever you need fast membership testing (in) or need to guarantee uniqueness.

Set Operations​

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

a | b   # union           {1, 2, 3, 4, 5, 6}
a & b   # intersection    {3, 4}
a - b   # difference      {1, 2}  (in a but not b)
a ^ b   # symmetric diff  {1, 2, 5, 6}  (in one but not both)
a <= b  # subset check

See Sets in the docs.

Set Comprehensions​

unique_lengths = {len(word) for word in ["cat", "dog", "elephant", "ox"]}
# {2, 3, 8}

Nested Dictionaries​

Dictionaries can hold other dictionaries as values:

database = {
    "alice": {"age": 30, "role": "admin"},
    "bob":   {"age": 25, "role": "user"},
}
database["alice"]["role"]   # "admin"
