Functions

Functions are the fundamental building blocks of reusable code. In this module you will learn to define functions with def, work with parameters and return values, use default arguments and flexible signatures with *args/**kwargs, write concise lambda functions, and understand variable scope. You will also learn to document your functions with docstrings.

Learning Objectives​

  • Define and call functions using def
  • Understand positional, keyword, and default parameters
  • Use *args and **kwargs for flexible function signatures
  • Write lambda expressions for simple one-liners
  • Explain local vs. global scope
  • Write docstrings that describe function behaviour

Theory​

Defining Functions​

Use the def keyword, followed by the function name, parenthesised parameters, and a colon. The body is indented:

def greet(name):
    print(f"Hello, {name}!")

greet("Alice")   # Hello, Alice!

A function without an explicit return statement returns None.

Return Values​

Use return to send a value back to the caller:

def add(a, b):
    return a + b

result = add(3, 4)   # result = 7

A function can return multiple values as a tuple:

def min_max(lst):
    return min(lst), max(lst)

lo, hi = min_max([3, 1, 4, 1, 5])   # lo=1, hi=5

Default Arguments​

Parameters can have default values. Defaults must come after non-default parameters:

def power(base, exponent=2):
    return base ** exponent

power(3)      # 9   — uses default exponent
power(3, 3)   # 27  — overrides default
tip

Use immutable defaults (numbers, strings, None) — never mutable defaults like [] or {}. Mutable defaults are shared across all calls, which leads to subtle bugs.

*args and **kwargs​

  • *args collects extra positional arguments into a tuple
  • **kwargs collects extra keyword arguments into a dict
def total(*args):
    return sum(args)

total(1, 2, 3, 4)   # 10

def info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

info(name="Alice", age=30)

See Arbitrary Argument Lists in the docs.

Lambda Expressions​

A lambda creates a small anonymous function in a single expression:

square = lambda x: x ** 2
square(5)   # 25

# Useful as a key function:
pairs = [(1, "b"), (2, "a"), (3, "c")]
sorted(pairs, key=lambda p: p[1])  # sort by second element
note

Lambdas are limited to a single expression. For anything more complex, use a regular def.

Scope​

Python uses LEGB scope resolution: Local → Enclosing → Global → Built-in.

x = 10   # global

def show():
    x = 20       # local — does NOT affect the global x
    print(x)     # 20

show()
print(x)   # 10

Use global to modify a global variable inside a function (generally avoid this):

counter = 0
def increment():
    global counter
    counter += 1

See Scopes and Namespaces.

Docstrings​

A docstring is a string literal placed as the first statement in a function. It documents the function's purpose, parameters, and return value:

def celsius_to_fahrenheit(celsius):
    """Convert a temperature from Celsius to Fahrenheit.

    Args:
        celsius (float): Temperature in degrees Celsius.

    Returns:
        float: Temperature in degrees Fahrenheit.
    """
    return celsius * 9 / 5 + 32

Access a docstring with help(celsius_to_fahrenheit) or celsius_to_fahrenheit.__doc__.
