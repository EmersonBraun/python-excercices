# Variables & Types

In this module you will learn how Python stores data using **variables**, explore the four fundamental **data types**, convert between them, and format output with **f-strings**. By the end you will be comfortable declaring variables, reasoning about their types, and manipulating strings and numbers in Python.

## Learning Objectives

- Understand Python variables and assignment
- Know the basic data types (`int`, `float`, `str`, `bool`)
- Use type conversion functions
- Work with f-strings for output

---

## Theory

### Variables

A variable in Python is a name that refers to a value stored in memory. You create a variable with a simple **assignment statement** using the `=` operator:

```python
age = 25
greeting = "Hello"
pi = 3.14159
```

Unlike many other languages, Python does not require you to declare a type — the type is inferred automatically from the value you assign. You can even reassign a variable to a completely different type later, although doing so is generally discouraged for readability.

Variable names must start with a letter or underscore, can contain letters, digits, and underscores, and are **case-sensitive** (`age` and `Age` are different variables). The Python community follows the `snake_case` convention for variable and function names (e.g. `my_variable`, `total_count`).

:::tip
Choose descriptive names. `x = 30` tells the reader nothing; `temperature_celsius = 30` is immediately clear.
:::

For more details see the [Python Tutorial — An Informal Introduction](https://docs.python.org/3/tutorial/introduction.html).

### Data Types

Python has four fundamental built-in types you will use constantly:

| Type    | Example          | Description                        |
|---------|------------------|------------------------------------|
| `int`   | `42`, `-7`, `0`  | Whole numbers (unlimited precision)|
| `float` | `3.14`, `-0.5`   | Decimal (floating-point) numbers   |
| `str`   | `"hello"`, `'hi'`| Text enclosed in quotes            |
| `bool`  | `True`, `False`  | Logical truth values               |

You can check any value's type with the built-in `type()` function:

```python
type(42)        # <class 'int'>
type(3.14)      # <class 'float'>
type("hello")   # <class 'str'>
type(True)      # <class 'bool'>
```

:::note
In Python, `bool` is a subclass of `int`. `True` equals `1` and `False` equals `0`, so you can use booleans in arithmetic expressions — but that does not mean you should.
:::

See the [Built-in Types](https://docs.python.org/3/library/stdtypes.html) documentation for a comprehensive reference.

### Type Conversion

Python provides built-in functions to convert between types:

```python
int("42")       # 42       — string to int
float("3.14")   # 3.14     — string to float
str(100)        # "100"    — int to string
bool(0)         # False    — int to bool (0 is falsy)
bool("")        # False    — empty string is falsy
bool("hello")   # True     — non-empty string is truthy
int(3.9)        # 3        — truncates, does NOT round
```

:::tip
`int()` truncates toward zero. If you need rounding, use `round()` instead: `round(3.9)` returns `4`.
:::

See [Built-in Functions](https://docs.python.org/3/library/functions.html) for the full list.

### String Formatting

Python offers several ways to build strings from variables. The modern, preferred approach is **f-strings** (formatted string literals), available since Python 3.6:

```python
name = "Alice"
age = 30
print(f"My name is {name} and I am {age} years old.")
```

You can put any valid expression inside the braces:

```python
print(f"Next year I will be {age + 1}.")
print(f"Pi to 2 decimals: {3.14159:.2f}")
```

Older alternatives include the `.format()` method and `%` formatting:

```python
# .format()
"Hello, {}!".format(name)

# % formatting (legacy)
"Hello, %s!" % name
```

:::note
Stick with f-strings for new code. They are faster, more readable, and less error-prone than the alternatives.
:::

See [Format String Syntax](https://docs.python.org/3/library/string.html#formatstrings) for advanced formatting options.
