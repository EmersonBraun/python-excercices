Lists & Tuples

Lists and tuples are Python's two primary sequence types. Lists are mutable and packed with useful methods; tuples are immutable and ideal for fixed collections of values. In this module you will learn to create, index, slice, and transform both types, and discover the elegant power of list comprehensions.

Learning Objectives​

  • Create and modify lists using indexing, slicing, and common methods
  • Understand the difference between mutable lists and immutable tuples
  • Use list comprehensions to build lists concisely
  • Unpack sequences into variables
  • Apply sorting, searching, and aggregation functions to sequences

Theory​

List Basics​

A list is an ordered, mutable collection of items enclosed in square brackets:

fruits = ["apple", "banana", "cherry"]
mixed  = [1, "hello", 3.14, True]  # can hold any types
empty  = []

Access elements by zero-based index. Negative indices count from the end:

fruits[0]   # "apple"
fruits[-1]  # "cherry"
fruits[1:3] # ["banana", "cherry"]  (slice)

List Methods​

lst = [3, 1, 4, 1, 5]

lst.append(9)         # [3, 1, 4, 1, 5, 9]   — add to end
lst.insert(0, 0)      # [0, 3, 1, 4, 1, 5, 9] — insert at index
lst.remove(1)         # removes first occurrence of 1
lst.pop()             # removes and returns last element
lst.pop(0)            # removes and returns element at index 0
lst.sort()            # sorts in-place (ascending)
lst.sort(reverse=True)# sorts descending
lst.reverse()         # reverses in-place
lst.count(1)          # how many times 1 appears
lst.index(4)          # index of first occurrence of 4
lst.extend([7, 8])    # append all items from another iterable
tip

sort() modifies the list in-place and returns None. If you need a new sorted list, use the built-in sorted(lst) instead.

See list methods in the docs.

List Comprehensions​

A list comprehension is a compact way to build a list from an iterable:

# Basic form: [expression for item in iterable]
squares = [x ** 2 for x in range(1, 6)]   # [1, 4, 9, 16, 25]

# With a filter condition:
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]

# Nested:
pairs = [(x, y) for x in range(3) for y in range(3)]
note

List comprehensions are often faster and more readable than equivalent for loops with .append(). Use them for simple transformations; stick to regular loops for complex logic.

Tuples​

A tuple is an ordered, immutable sequence enclosed in parentheses:

point = (3, 4)
rgb   = (255, 128, 0)
single = (42,)   # note the trailing comma — required for single-element tuples!

Because tuples cannot be changed after creation, they are:

  • Safe to use as dictionary keys
  • Slightly faster and more memory-efficient than lists
  • A good choice for fixed collections (coordinates, records, etc.)

Tuples support the same indexing and slicing as lists.

Unpacking​

Both lists and tuples can be unpacked into individual variables:

x, y = (3, 4)
first, *rest = [1, 2, 3, 4, 5]   # first=1, rest=[2,3,4,5]
a, b, c = "abc"                   # works on any iterable

See Tuples and Sequences for more.
