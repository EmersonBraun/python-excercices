Input, Output & Strings

In this module you will master Python's primary output tool — print() — and dive deep into strings: how to create them, transform them with methods, slice them, and format them for display. By the end you will be able to manipulate text fluently and produce well-formatted output.

Learning Objectives​

  • Use print() with multiple arguments, separators, and end characters
  • Apply common string methods (.upper(), .lower(), .strip(), .split(), .join(), .replace())
  • Slice strings with index notation
  • Use escape characters inside strings
  • Understand why input() is replaced by function parameters in browser exercises

Theory​

print()​

print() sends output to the console. It accepts any number of arguments separated by commas, and by default joins them with a space and adds a newline at the end:

print("Hello", "world")          # Hello world
print("Hello", "world", sep="-") # Hello-world
print("No newline", end="")      # stays on same line
print(42, 3.14, True)            # 42 3.14 True

See the print() documentation for all parameters.

note

In these browser exercises, input() is not available because the environment runs Python via Pyodide (no interactive terminal). Exercises that would normally read user input instead accept the value as a function parameter.

String Methods​

Strings in Python are immutable sequences of characters. They come with a rich set of built-in methods that return new strings:

text = "  Hello, World!  "

text.upper()          # "  HELLO, WORLD!  "
text.lower()          # "  hello, world!  "
text.strip()          # "Hello, World!"   — removes leading/trailing whitespace
text.lstrip()         # "Hello, World!  " — left side only
text.rstrip()         # "  Hello, World!" — right side only

text.replace("World", "Python")  # "  Hello, Python!  "

csv = "a,b,c,d"
csv.split(",")        # ["a", "b", "c", "d"]
"-".join(["a", "b", "c"])  # "a-b-c"

"hello".startswith("he")  # True
"hello".endswith("lo")    # True
"hello".find("ll")        # 2  (index of first occurrence)
"hello".count("l")        # 2
tip

Methods can be chained: " HELLO ".strip().lower() gives "hello".

See String Methods for the complete list.

String Slicing​

Strings support index-based access and slicing using the [start:stop:step] syntax:

s = "Python"
s[0]      # "P"   — first character (index 0)
s[-1]     # "n"   — last character
s[1:4]    # "yth" — indices 1, 2, 3 (stop is exclusive)
s[:3]     # "Pyt" — from beginning to index 3
s[3:]     # "hon" — from index 3 to end
s[::-1]   # "nohtyP" — reversed
s[::2]    # "Pto" — every other character
note

Python uses zero-based indexing. Negative indices count from the end: s[-1] is the last character, s[-2] is the second-to-last, and so on.

Escape Characters​

Inside string literals you can embed special characters using backslash sequences:

SequenceMeaning
\nNewline
\tTab
\\Literal \
\'Single quote
\"Double quote
print("Line 1\nLine 2")     # two lines
print("Name:\tAlice")       # tab between label and value
print("She said \"hi\"")    # embedded quotes

Alternatively, use raw strings (r"...") to suppress all escape processing:

path = r"C:\Users\name\docs"   # backslashes are literal
