# Decorators & Generators

In this module you will master two of Python's most powerful features: **decorators** that wrap and enhance functions without modifying them, and **generators** that produce values lazily for memory-efficient iteration. By the end you will be able to write reusable decorators, create infinite sequences with `yield`, and use `itertools` to compose pipelines.

## Learning Objectives

- Understand the decorator pattern and `@syntax`
- Write decorators with and without arguments
- Use `functools.wraps` to preserve metadata
- Create generator functions using `yield`
- Write generator expressions
- Combine generators with `itertools`

---

## Theory

### Decorators

A **decorator** is a function that takes another function as its argument, wraps it with additional behaviour, and returns the wrapped version. The `@` syntax is shorthand for `func = decorator(func)`:

```python
import functools

def shout(func):
    @functools.wraps(func)  # preserves __name__, __doc__, etc.
    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        return str(result).upper()
    return wrapper

@shout
def greet(name):
    return f"hello, {name}"

greet("alice")   # "HELLO, ALICE"
```

:::tip
Always apply `@functools.wraps(func)` to your inner `wrapper` function. Without it, the decorated function loses its original `__name__` and `__doc__`, which breaks introspection and debugging.
:::

### Decorators with Arguments

To pass arguments to a decorator you add a third layer — a factory function that returns the actual decorator:

```python
def repeat(n):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(n):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def say(msg):
    print(msg)

say("hi")   # prints "hi" three times
```

### Class Decorators

Classes can also be decorators if they implement `__call__`:

```python
class Counter:
    def __init__(self, func):
        functools.update_wrapper(self, func)
        self.func = func
        self.calls = 0

    def __call__(self, *args, **kwargs):
        self.calls += 1
        return self.func(*args, **kwargs)

@Counter
def add(a, b):
    return a + b

add(1, 2)
add(3, 4)
print(add.calls)   # 2
```

See [Decorators](https://docs.python.org/3/glossary.html#term-decorator) in the Python glossary.

### Generators

A **generator function** uses `yield` instead of `return`. Calling it returns a **generator object** that produces values one at a time — only computing each value when requested (lazy evaluation):

```python
def count_up(start, stop):
    n = start
    while n <= stop:
        yield n
        n += 1

for x in count_up(1, 5):
    print(x)   # 1, 2, 3, 4, 5
```

Generators are ideal for large or infinite sequences because they never hold all values in memory at once.

### Generator Expressions

Like list comprehensions but with `()` — create a generator without defining a function:

```python
squares = (x**2 for x in range(1_000_000))   # no memory spike
total = sum(squares)
```

### itertools Basics

The `itertools` module provides composable tools for generator pipelines:

| Function | Description |
|----------|-------------|
| `itertools.count(start)` | Infinite counter |
| `itertools.cycle(iterable)` | Repeat iterable forever |
| `itertools.islice(gen, n)` | Take first n items |
| `itertools.takewhile(pred, gen)` | Yield while predicate is True |
| `itertools.dropwhile(pred, gen)` | Skip while predicate is True |
| `itertools.chain(*iters)` | Concatenate iterables |

```python
import itertools

fib_under_100 = list(itertools.takewhile(lambda x: x < 100, fibonacci_gen()))
```

See [itertools — Functions creating iterators for efficient looping](https://docs.python.org/3/library/itertools.html).
