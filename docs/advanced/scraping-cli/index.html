Web Scraping & CLI Tools

In this module you will learn web scraping patterns — extracting structured data from HTML — and how to build command-line interface (CLI) tools with Python's argparse module. Because BeautifulSoup may not be available in the browser sandbox without micropip, the scraping exercises use mock HTML strings with regex and string methods (the same patterns you'd apply to real HTML). For CLI exercises, you test argparse parsers using explicit argument lists.

Learning Objectives​

  • Parse HTML strings using string methods and re
  • Extract data with CSS selector-like patterns
  • Understand the BeautifulSoup API for real-world use
  • Build CLI tools with argparse
  • Define positional and optional arguments
  • Test CLIs with parse_args() on explicit argument lists

Theory​

HTML Structure​

HTML is a tree of elements (tags) that contain text and attributes:

<html>
  <body>
    <h1 class="title">Hello World</h1>
    <ul id="items">
      <li><a href="/page/1">Page 1</a></li>
      <li><a href="/page/2">Page 2</a></li>
    </ul>
  </body>
</html>

Web scraping extracts data from this structure programmatically.

BeautifulSoup (Real-World)​

In a real Python environment you'd install beautifulsoup4 and use:

from bs4 import BeautifulSoup

soup = BeautifulSoup(html_string, "html.parser")

# Find by tag
title = soup.find("h1").text              # "Hello World"

# Find all links
links = soup.find_all("a")
hrefs = [a["href"] for a in links]        # ["/page/1", "/page/2"]

# CSS selectors
items = soup.select("ul#items li a")      # all <a> inside the list

Parsing with re (Browser-Compatible)​

In the browser sandbox we use re to extract data from HTML strings:

import re

html = '<a href="/page/1">Page 1</a><a href="/page/2">Page 2</a>'

# Extract all href values
hrefs = re.findall(r'href="([^"]+)"', html)   # ['/page/1', '/page/2']

# Extract text between tags
texts = re.findall(r'<a[^>]*>([^<]+)</a>', html)  # ['Page 1', 'Page 2']
tip

re.findall(pattern, text) returns a list of all matches. If the pattern has one capture group (...), it returns the captured strings. With multiple groups, it returns a list of tuples.

See re — Regular expression operations.

argparse — CLI Tools​

argparse is Python's standard library for building command-line interfaces:

import argparse

parser = argparse.ArgumentParser(description="My CLI tool")

# Positional argument (required)
parser.add_argument("filename", help="Input file path")

# Optional argument (flag)
parser.add_argument("--verbose", "-v", action="store_true", help="Verbose output")

# Optional argument with value
parser.add_argument("--output", "-o", default="output.txt", help="Output file")

# Numeric argument with type conversion
parser.add_argument("--count", type=int, default=10, help="Number of results")

In production, call parser.parse_args() with no arguments (reads sys.argv). In tests, pass an explicit list:

args = parser.parse_args(["myfile.txt", "--verbose", "--count", "5"])
print(args.filename)   # "myfile.txt"
print(args.verbose)    # True
print(args.count)      # 5

See argparse — Parser for command-line options.
