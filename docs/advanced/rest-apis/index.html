REST APIs & HTTP

In this module you will learn how web applications communicate over HTTP, how to work with JSON data, how to use the requests library patterns for GET, POST, PUT, and DELETE operations, and how to handle API authentication and errors. Because real HTTP calls don't work inside the browser sandbox, the exercises use a mock requests object that behaves identically to the real library — so you learn the exact same patterns you'd use in production.

Learning Objectives​

  • Understand HTTP methods: GET, POST, PUT, DELETE
  • Parse and build JSON with Python's json module
  • Use requests.get(), requests.post(), requests.put(), requests.delete()
  • Handle HTTP errors and status codes
  • Pass headers (e.g., API keys, Bearer tokens)
  • Understand RESTful resource design

Theory​

HTTP Methods​

REST APIs communicate over HTTP using four primary methods:

MethodPurposeHas Body?
GETRetrieve a resourceNo
POSTCreate a new resourceYes
PUTReplace an existing resourceYes
DELETERemove a resourceNo

A resource is identified by a URL like https://api.example.com/users/42. The response includes a status code:

CodeMeaning
200OK
201Created
400Bad Request
401Unauthorized
404Not Found
500Internal Server Error

The requests Library​

The requests library is the standard Python HTTP client:

import requests

# GET
response = requests.get("https://api.example.com/users")
print(response.status_code)   # 200
data = response.json()        # parse JSON body

# POST
response = requests.post(
    "https://api.example.com/users",
    json={"name": "Alice", "email": "alice@example.com"}
)

# PUT
response = requests.put(
    "https://api.example.com/users/1",
    json={"name": "Alice Smith"}
)

# DELETE
response = requests.delete("https://api.example.com/users/1")

Authentication Headers​

Many APIs require an API key or Bearer token in the Authorization header:

headers = {"Authorization": "Bearer my_secret_token"}
response = requests.get("https://api.example.com/protected", headers=headers)

Error Handling​

Always check the status code or use response.raise_for_status():

response = requests.get(url)
if response.status_code == 200:
    data = response.json()
elif response.status_code == 404:
    print("Resource not found")
else:
    response.raise_for_status()   # raises HTTPError for 4xx/5xx

See Requests: HTTP for Humans.

JSON Module​

Python's built-in json module converts between Python objects and JSON strings:

import json

# Python -> JSON string
data = {"name": "Alice", "scores": [95, 87]}
json_str = json.dumps(data, indent=2)

# JSON string -> Python
parsed = json.loads(json_str)
print(parsed["name"])   # Alice

See json — JSON encoder and decoder.
