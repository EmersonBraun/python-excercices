Async Programming & Context Managers

In this module you will learn how Python handles asynchronous programming with async/await and asyncio, how to build and use context managers with the with statement, and how to add type annotations to make your code self-documenting. By the end you will be able to write concurrent async programs, create custom context managers, and annotate function signatures.

Learning Objectives​

  • Write async def functions and await coroutines
  • Use asyncio.gather to run tasks concurrently
  • Implement context managers with __enter__/__exit__
  • Build context managers with @contextmanager
  • Add type annotations to functions and variables

Theory​

async / await Basics​

Python's asyncio library allows cooperative multitasking: while one coroutine waits for I/O, other coroutines can run. You define a coroutine with async def and pause it with await:

import asyncio

async def greet(name, delay):
    await asyncio.sleep(delay)   # yields control while waiting
    print(f"Hello, {name}!")

asyncio.run(greet("Alice", 1))
note

In Pyodide (the browser runtime used for these exercises), use asyncio.run() to execute async code from synchronous context. Pyodide supports runPythonAsync under the hood.

asyncio.gather — Concurrent Tasks​

asyncio.gather(*coroutines) runs multiple coroutines concurrently and waits for all of them:

async def main():
    # These two run at the same time — total ~1s, not ~2s
    await asyncio.gather(
        greet("Alice", 0.5),
        greet("Bob", 1.0),
    )

asyncio.run(main())

See asyncio — Asynchronous I/O.

Context Managers — with Statement​

The with statement guarantees setup and teardown, even if an exception occurs. Any object that implements __enter__ and __exit__ can be used:

class ManagedResource:
    def __enter__(self):
        print("Acquiring resource")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Releasing resource")
        return False   # False = don't suppress exceptions

with ManagedResource() as r:
    print("Using resource")

contextlib.contextmanager​

The @contextmanager decorator lets you write context managers as generator functions — cleaner for simple cases:

from contextlib import contextmanager

@contextmanager
def timer(label="block"):
    import time
    start = time.perf_counter()
    try:
        yield          # code inside the `with` block runs here
    finally:
        elapsed = time.perf_counter() - start
        print(f"{label} took {elapsed:.4f}s")

with timer("my work"):
    sum(range(1_000_000))

See contextlib.

Type Annotations​

Python type annotations are hints for humans and tools — they do not affect runtime behaviour:

def greet(name: str, times: int = 1) -> str:
    return (f"Hello, {name}!\n" * times).strip()

age: int = 30
scores: list[int] = [95, 87, 92]
lookup: dict[str, int] = {"a": 1, "b": 2}

Use from typing import Optional, Union, Callable for more complex types (Python 3.9 and below require from typing import List, Dict).

See typing — Support for type hints.
