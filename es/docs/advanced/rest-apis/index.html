REST APIs y HTTP

En este módulo aprenderás cómo las aplicaciones web se comunican mediante HTTP, cómo trabajar con datos JSON, cómo usar los patrones de la biblioteca requests para operaciones GET, POST, PUT y DELETE, y cómo manejar la autenticación y los errores de API. Dado que las llamadas HTTP reales no funcionan dentro del sandbox del navegador, los ejercicios usan un objeto requests simulado que se comporta de manera idéntica a la biblioteca real — así aprenderás exactamente los mismos patrones que usarías en producción.

Objetivos de Aprendizaje​

  • Entender los métodos HTTP: GET, POST, PUT, DELETE
  • Parsear y construir JSON con el módulo json de Python
  • Usar requests.get(), requests.post(), requests.put(), requests.delete()
  • Manejar errores HTTP y códigos de estado
  • Pasar encabezados (por ejemplo, claves de API, tokens Bearer)
  • Entender el diseño de recursos RESTful

Teoría​

Métodos HTTP​

Las APIs REST se comunican a través de HTTP usando cuatro métodos principales:

MétodoPropósito¿Tiene Cuerpo?
GETRecuperar un recursoNo
POSTCrear un nuevo recursoSí
PUTReemplazar un recurso existenteSí
DELETEEliminar un recursoNo

Un recurso se identifica por una URL como https://api.example.com/users/42. La respuesta incluye un código de estado:

CódigoSignificado
200OK
201Creado
400Solicitud Incorrecta
401No Autorizado
404No Encontrado
500Error Interno del Servidor

La Biblioteca requests​

La biblioteca requests es el cliente HTTP estándar de Python:

import requests

# GET
response = requests.get("https://api.example.com/users")
print(response.status_code)   # 200
data = response.json()        # parse JSON body

# POST
response = requests.post(
    "https://api.example.com/users",
    json={"name": "Alice", "email": "alice@example.com"}
)

# PUT
response = requests.put(
    "https://api.example.com/users/1",
    json={"name": "Alice Smith"}
)

# DELETE
response = requests.delete("https://api.example.com/users/1")

Encabezados de Autenticación​

Muchas APIs requieren una clave de API o un token Bearer en el encabezado Authorization:

headers = {"Authorization": "Bearer my_secret_token"}
response = requests.get("https://api.example.com/protected", headers=headers)

Manejo de Errores​

Siempre verifica el código de estado o usa response.raise_for_status():

response = requests.get(url)
if response.status_code == 200:
    data = response.json()
elif response.status_code == 404:
    print("Resource not found")
else:
    response.raise_for_status()   # raises HTTPError for 4xx/5xx

Módulo JSON​

El módulo json integrado de Python convierte entre objetos Python y cadenas JSON:

import json

# Python -> JSON string
data = {"name": "Alice", "scores": [95, 87]}
json_str = json.dumps(data, indent=2)

# JSON string -> Python
parsed = json.loads(json_str)
print(parsed["name"])   # Alice
