Bases de Datos y SQLite

En este módulo aprenderás a almacenar y consultar datos estructurados usando SQL y el módulo sqlite3 integrado de Python. Escribirás instrucciones CREATE TABLE, INSERT, SELECT, UPDATE y DELETE, usarás consultas parametrizadas para prevenir inyección SQL, y realizarás consultas JOIN y de agregación. Dado que sqlite3 está disponible de forma nativa en Pyodide, todos los ejercicios se ejecutan directamente en el navegador usando bases de datos en memoria.

Objetivos de Aprendizaje​

  • Entender los conceptos de bases de datos relacionales (tablas, filas, columnas)
  • Escribir SQL básico: CREATE, INSERT, SELECT, UPDATE, DELETE
  • Usar el módulo sqlite3 de Python con gestores de contexto
  • Escribir consultas parametrizadas con marcadores de posición
  • Realizar consultas JOIN entre tablas
  • Usar funciones de agregación: COUNT, SUM, AVG, MIN, MAX

Teoría​

Conectarse a SQLite​

El módulo sqlite3 de Python está incluido en la biblioteca estándar. Usa :memory: para una base de datos en memoria que desaparece cuando el programa termina — perfecto para pruebas:

import sqlite3

# In-memory database (no file needed — great for Pyodide!)
conn = sqlite3.connect(':memory:')
cursor = conn.cursor()

Siempre cierra la conexión cuando termines, o usa un gestor de contexto:

with sqlite3.connect(':memory:') as conn:
    cursor = conn.cursor()
    # ...

Consulta sqlite3 — Interfaz DB-API 2.0.

Crear Tablas​

CREATE TABLE users (
    id      INTEGER PRIMARY KEY AUTOINCREMENT,
    name    TEXT    NOT NULL,
    email   TEXT    UNIQUE,
    age     INTEGER
);
conn.execute("""
    CREATE TABLE users (
        id    INTEGER PRIMARY KEY AUTOINCREMENT,
        name  TEXT NOT NULL,
        email TEXT UNIQUE,
        age   INTEGER
    )
""")
conn.commit()

INSERT​

# Never use string formatting — always use parameterized queries!
conn.execute(
    "INSERT INTO users (name, email, age) VALUES (?, ?, ?)",
    ("Alice", "alice@example.com", 30)
)

# Insert many rows at once
rows = [("Bob", "bob@example.com", 25), ("Carol", "carol@example.com", 35)]
conn.executemany("INSERT INTO users (name, email, age) VALUES (?, ?, ?)", rows)
conn.commit()
aviso

Nunca construyas consultas SQL con concatenación de cadenas como f"...WHERE name = '{name}'". Esto crea una vulnerabilidad de inyección SQL. Siempre usa marcadores de posición ?.

SELECT​

cursor = conn.execute("SELECT id, name, age FROM users WHERE age > ?", (25,))
rows = cursor.fetchall()     # list of tuples

# Or use fetchone() for a single row
row = conn.execute("SELECT * FROM users WHERE id = ?", (1,)).fetchone()

conn.row_factory = sqlite3.Row hace que las filas sean accesibles por nombre de columna:

conn.row_factory = sqlite3.Row
row = conn.execute("SELECT * FROM users WHERE id = 1").fetchone()
print(row["name"])   # Alice

UPDATE y DELETE​

conn.execute("UPDATE users SET age = ? WHERE id = ?", (31, 1))
conn.execute("DELETE FROM users WHERE age < ?", (18,))
conn.commit()

Agregaciones​

count = conn.execute("SELECT COUNT(*) FROM users").fetchone()[0]
avg   = conn.execute("SELECT AVG(age) FROM users").fetchone()[0]
total = conn.execute("SELECT SUM(salary) FROM employees").fetchone()[0]

JOINs​

SELECT u.name, o.product, o.amount
FROM users u
JOIN orders o ON u.id = o.user_id
WHERE u.name = 'Alice';
