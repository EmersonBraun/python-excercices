Entrada, Salida y Cadenas

En este módulo dominarás la herramienta principal de salida de Python — print() — y profundizarás en las cadenas: cómo crearlas, transformarlas con métodos, segmentarlas y formatearlas para mostrarlas. Al final podrás manipular texto con fluidez y producir una salida bien formateada.

Objetivos de Aprendizaje​

  • Usar print() con múltiples argumentos, separadores y caracteres de fin
  • Aplicar métodos comunes de cadenas (.upper(), .lower(), .strip(), .split(), .join(), .replace())
  • Segmentar cadenas con notación de índices
  • Usar caracteres de escape dentro de cadenas
  • Entender por qué input() es reemplazado por parámetros de función en los ejercicios del navegador

Teoría​

print()​

print() envía salida a la consola. Acepta cualquier número de argumentos separados por comas, y por defecto los une con un espacio y agrega una nueva línea al final:

print("Hello", "world")          # Hello world
print("Hello", "world", sep="-") # Hello-world
print("No newline", end="")      # stays on same line
print(42, 3.14, True)            # 42 3.14 True

Consulta la documentación de print() para todos los parámetros.

nota

En estos ejercicios del navegador, input() no está disponible porque el entorno ejecuta Python a través de Pyodide (sin terminal interactiva). Los ejercicios que normalmente leerían la entrada del usuario aceptan el valor como un parámetro de función en su lugar.

Métodos de Cadenas​

Las cadenas en Python son secuencias inmutables de caracteres. Vienen con un rico conjunto de métodos integrados que devuelven cadenas nuevas:

text = "  Hello, World!  "

text.upper()          # "  HELLO, WORLD!  "
text.lower()          # "  hello, world!  "
text.strip()          # "Hello, World!"   — removes leading/trailing whitespace
text.lstrip()         # "Hello, World!  " — left side only
text.rstrip()         # "  Hello, World!" — right side only

text.replace("World", "Python")  # "  Hello, Python!  "

csv = "a,b,c,d"
csv.split(",")        # ["a", "b", "c", "d"]
"-".join(["a", "b", "c"])  # "a-b-c"

"hello".startswith("he")  # True
"hello".endswith("lo")    # True
"hello".find("ll")        # 2  (index of first occurrence)
"hello".count("l")        # 2
tip

Los métodos pueden encadenarse: " HELLO ".strip().lower() da "hello".

Consulta Métodos de Cadenas para la lista completa.

Segmentación de Cadenas​

Las cadenas admiten acceso por índice y segmentación usando la sintaxis [inicio:fin:paso]:

s = "Python"
s[0]      # "P"   — first character (index 0)
s[-1]     # "n"   — last character
s[1:4]    # "yth" — indices 1, 2, 3 (stop is exclusive)
s[:3]     # "Pyt" — from beginning to index 3
s[3:]     # "hon" — from index 3 to end
s[::-1]   # "nohtyP" — reversed
s[::2]    # "Pto" — every other character
nota

Python usa índices basados en cero. Los índices negativos cuentan desde el final: s[-1] es el último carácter, s[-2] es el penúltimo, y así sucesivamente.

Caracteres de Escape​

Dentro de los literales de cadena puedes insertar caracteres especiales usando secuencias de barra invertida:

SecuenciaSignificado
\nNueva línea
\tTabulación
\\\ literal
\'Comilla simple
\"Comilla doble
print("Line 1\nLine 2")     # two lines
print("Name:\tAlice")       # tab between label and value
print("She said \"hi\"")    # embedded quotes

Alternativamente, usa cadenas crudas (r"...") para suprimir todo el procesamiento de escapes:

path = r"C:\Users\name\docs"   # backslashes are literal
