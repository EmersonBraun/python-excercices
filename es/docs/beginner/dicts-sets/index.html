Diccionarios, Conjuntos y Comprensiones

Los diccionarios y los conjuntos son los tipos de colección no ordenada principales de Python. Los diccionarios mapean claves a valores y están en todas partes en el código Python del mundo real. Los conjuntos almacenan elementos únicos y admiten pruebas de membresía rápidas y operaciones matemáticas de conjuntos. En este módulo también dominarás las comprensiones de diccionarios y conjuntos para código conciso y expresivo.

Objetivos de Aprendizaje​

  • Crear, acceder y modificar diccionarios
  • Usar métodos comunes de diccionarios (.get(), .keys(), .values(), .items(), .update(), .pop())
  • Crear conjuntos y realizar operaciones de unión, intersección y diferencia
  • Escribir comprensiones de diccionarios y conjuntos
  • Trabajar con diccionarios anidados

Teoría​

Fundamentos de Diccionarios​

Un diccionario es un mapeo ordenado (Python 3.7+) de claves únicas a valores, entre llaves:

person = {"name": "Alice", "age": 30, "city": "NYC"}
empty  = {}

Accede a los valores por clave. Las claves faltantes generan KeyError — usa .get() para proporcionar un valor predeterminado:

person["name"]              # "Alice"
person.get("email")         # None    (key missing, no error)
person.get("email", "N/A")  # "N/A"  (explicit default)

Agrega, actualiza y elimina entradas:

person["email"] = "alice@example.com"   # add
person["age"] = 31                       # update
del person["city"]                       # delete
popped = person.pop("email")             # remove and return

Métodos de Diccionarios​

d = {"a": 1, "b": 2, "c": 3}

d.keys()           # dict_keys(["a", "b", "c"])
d.values()         # dict_values([1, 2, 3])
d.items()          # dict_items([("a", 1), ("b", 2), ("c", 3)])

d.update({"d": 4, "a": 10})  # merge another dict (overrides existing keys)
d.setdefault("e", 0)          # insert key with default if not present

# Iterate:
for key, value in d.items():
    print(f"{key} -> {value}")

Comprensiones de Diccionarios​

squares = {x: x**2 for x in range(1, 6)}
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Filter with a condition:
even_squares = {x: x**2 for x in range(10) if x % 2 == 0}

# Invert a dictionary:
original = {"a": 1, "b": 2, "c": 3}
inverted = {v: k for k, v in original.items()}
# {1: "a", 2: "b", 3: "c"}

Fundamentos de Conjuntos​

Un conjunto es una colección no ordenada de elementos únicos, también entre llaves:

fruits = {"apple", "banana", "cherry", "apple"}  # "apple" stored once
empty_set = set()   # NOT {} — that creates an empty dict!
fruits.add("mango")         # add one element
fruits.remove("banana")     # remove (raises KeyError if missing)
fruits.discard("banana")    # remove (no error if missing)
"cherry" in fruits          # True — O(1) membership test
tip

Usa un conjunto en lugar de una lista cuando necesites pruebas de membresía rápidas (in) o necesites garantizar la unicidad.

Operaciones con Conjuntos​

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

a | b   # union           {1, 2, 3, 4, 5, 6}
a & b   # intersection    {3, 4}
a - b   # difference      {1, 2}  (in a but not b)
a ^ b   # symmetric diff  {1, 2, 5, 6}  (in one but not both)
a <= b  # subset check

Comprensiones de Conjuntos​

unique_lengths = {len(word) for word in ["cat", "dog", "elephant", "ox"]}
# {2, 3, 8}

Diccionarios Anidados​

Los diccionarios pueden contener otros diccionarios como valores:

database = {
    "alice": {"age": 30, "role": "admin"},
    "bob":   {"age": 25, "role": "user"},
}
database["alice"]["role"]   # "admin"
