Entrada/Salida de Archivos

En este módulo aprenderás cómo Python lee y escribe archivos usando la función integrada open(), cómo manejar datos CSV y JSON, y cómo gestionar recursos de forma segura con el gestor de contexto (instrucción with). Al final tendrás confianza para leer, escribir y transformar datos basados en archivos en Python.

Objetivos de Aprendizaje​

  • Abrir archivos en diferentes modos (r, w, a, rb)
  • Leer y escribir archivos de texto de forma segura con gestores de contexto
  • Analizar y escribir datos CSV usando el módulo csv
  • Serializar y deserializar JSON con el módulo json
  • Usar io.StringIO para objetos similares a archivos en memoria (compatible con Pyodide)

Teoría​

La Función open() y los Modos de Archivo​

Python abre archivos con la función integrada open(). El segundo argumento es el modo:

ModoSignificado
"r"Lectura (predeterminado) — el archivo debe existir
"w"Escritura — crea o sobreescribe el archivo
"a"Anexar — crea o agrega al final
"rb" / "wb"Lectura / escritura binaria
f = open("data.txt", "w")
f.write("Hello, file!")
f.close()           # always close when done
tip

Olvidar llamar a close() puede corromper archivos o dejar descriptores de archivo sin liberar. Usa la instrucción with (ver abajo) en su lugar — cierra el archivo automáticamente.

Consulta open() — Funciones Integradas para una referencia completa.

Gestores de Contexto — Instrucción with​

La instrucción with garantiza que el archivo se cierra cuando el bloque termina, incluso si ocurre una excepción:

with open("data.txt", "w") as f:
    f.write("Hello, file!\n")
    f.write("Second line.\n")
# file is automatically closed here

Leyendo el archivo de nuevo:

with open("data.txt", "r") as f:
    content = f.read()          # entire file as a string
    # — or —
    lines = f.readlines()       # list of lines
    # — or —
    for line in f:              # iterate line-by-line
        print(line.strip())
nota

En Pyodide (el runtime de Python en el navegador usado aquí) puedes escribir en el sistema de archivos virtual igual que en una máquina real. Los archivos solo existen durante la sesión de la página.

Consulta Lectura y Escritura de Archivos para más detalles.

io.StringIO — Archivos en Memoria​

io.StringIO proporciona un objeto similar a un archivo respaldado por una cadena en memoria. Es útil para probar código que espera un archivo sin tocar el disco:

import io

buffer = io.StringIO()
buffer.write("line one\n")
buffer.write("line two\n")
buffer.seek(0)               # rewind to the start
content = buffer.read()
print(content)

Consulta io — Herramientas principales para trabajar con streams.

Manejo de CSV​

El módulo csv simplifica la lectura y escritura de valores separados por comas:

import csv, io

# Write CSV to a StringIO buffer
output = io.StringIO()
writer = csv.writer(output)
writer.writerow(["name", "age", "city"])
writer.writerow(["Alice", 30, "London"])
writer.writerow(["Bob", 25, "Paris"])

# Read it back
output.seek(0)
reader = csv.DictReader(output)
for row in reader:
    print(row["name"], row["age"])
tip

Usa csv.DictReader para obtener cada fila como un diccionario con claves basadas en los nombres del encabezado — mucho más legible que indexar por número de columna.

Consulta csv — Lectura y Escritura de Archivos CSV.

Manejo de JSON​

El módulo json convierte objetos Python en cadenas JSON y viceversa:

import json

data = {"name": "Alice", "scores": [95, 87, 92], "active": True}

# Serialize Python → JSON string
json_str = json.dumps(data, indent=2)
print(json_str)

# Deserialize JSON string → Python
loaded = json.loads(json_str)
print(loaded["name"])        # Alice
print(loaded["scores"][0])   # 95

Usa json.dump() / json.load() cuando trabajes con objetos de archivo reales en lugar de cadenas.
