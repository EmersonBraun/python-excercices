## Curriculum Exercises (New)

45 exercises organized by difficulty level, from beginner to practical applications. Each exercise includes docstrings, expected input/output, difficulty rating, and estimated completion time.

| Level | Directory | Exercises | Topics |
|-------|-----------|-----------|--------|
| 1 | `level-1-foundations/` | 8 | Variables, I/O, conditionals, loops, strings, lists |
| 2 | `level-2-functions/` | 8 | Functions, recursion, dicts, sets, comprehensions |
| 3 | `level-3-intermediate/` | 8 | File I/O, exceptions, modules, classes |
| 4 | `level-4-oop/` | 6 | Inheritance, polymorphism, magic methods, patterns |
| 5 | `level-5-advanced/` | 7 | Decorators, generators, context managers, async, metaclasses |
| 6 | `level-6-practical/` | 8 | APIs, databases, testing, CLI tools, web scraping |

See [SUGGESTIONS.md](SUGGESTIONS.md) for the full curriculum plan.
