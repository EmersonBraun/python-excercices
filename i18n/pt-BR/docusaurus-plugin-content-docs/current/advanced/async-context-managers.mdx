# Programação Assíncrona & Gerenciadores de Contexto

Neste módulo você vai aprender como o Python lida com **programação assíncrona** usando `async`/`await` e `asyncio`, como construir e usar **gerenciadores de contexto** com a instrução `with`, e como adicionar **anotações de tipo** para tornar seu código auto-documentado. Ao final você será capaz de escrever programas assíncronos concorrentes, criar gerenciadores de contexto personalizados e anotar assinaturas de funções.

## Objetivos de Aprendizagem

- Escrever funções `async def` e usar `await` em corrotinas
- Usar `asyncio.gather` para executar tarefas de forma concorrente
- Implementar gerenciadores de contexto com `__enter__`/`__exit__`
- Construir gerenciadores de contexto com `@contextmanager`
- Adicionar anotações de tipo a funções e variáveis

---

## Teoria

### Fundamentos de async / await

A biblioteca `asyncio` do Python permite **multitarefa cooperativa**: enquanto uma corrotina aguarda por I/O, outras corrotinas podem executar. Você define uma corrotina com `async def` e a pausa com `await`:

```python
import asyncio

async def greet(name, delay):
    await asyncio.sleep(delay)   # yields control while waiting
    print(f"Hello, {name}!")

asyncio.run(greet("Alice", 1))
```

:::note
No Pyodide (o runtime do navegador usado nestes exercícios), use `asyncio.run()` para executar código assíncrono a partir de um contexto síncrono. O Pyodide suporta `runPythonAsync` internamente.
:::

### asyncio.gather — Tarefas Concorrentes

`asyncio.gather(*coroutines)` executa múltiplas corrotinas **de forma concorrente** e aguarda todas elas:

```python
async def main():
    # These two run at the same time — total ~1s, not ~2s
    await asyncio.gather(
        greet("Alice", 0.5),
        greet("Bob", 1.0),
    )

asyncio.run(main())
```

Consulte [asyncio — I/O Assíncrono](https://docs.python.org/3/library/asyncio.html).

### Gerenciadores de Contexto — Instrução `with`

A instrução `with` garante configuração e limpeza, mesmo se uma exceção ocorrer. Qualquer objeto que implemente `__enter__` e `__exit__` pode ser usado:

```python
class ManagedResource:
    def __enter__(self):
        print("Acquiring resource")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Releasing resource")
        return False   # False = don't suppress exceptions

with ManagedResource() as r:
    print("Using resource")
```

### `contextlib.contextmanager`

O decorator `@contextmanager` permite escrever gerenciadores de contexto como funções geradoras — mais limpo para casos simples:

```python
from contextlib import contextmanager

@contextmanager
def timer(label="block"):
    import time
    start = time.perf_counter()
    try:
        yield          # code inside the `with` block runs here
    finally:
        elapsed = time.perf_counter() - start
        print(f"{label} took {elapsed:.4f}s")

with timer("my work"):
    sum(range(1_000_000))
```

Consulte [contextlib](https://docs.python.org/3/library/contextlib.html).

### Anotações de Tipo

As anotações de tipo do Python são dicas para humanos e ferramentas — elas **não** afetam o comportamento em tempo de execução:

```python
def greet(name: str, times: int = 1) -> str:
    return (f"Hello, {name}!\n" * times).strip()

age: int = 30
scores: list[int] = [95, 87, 92]
lookup: dict[str, int] = {"a": 1, "b": 2}
```

Use `from typing import Optional, Union, Callable` para tipos mais complexos (Python 3.9 e abaixo requerem `from typing import List, Dict`).

Consulte [typing — Suporte para dicas de tipo](https://docs.python.org/3/library/typing.html).

### Exercício 6 — Gerenciador de Contexto Assíncrono

<PythonRunner
  title="Async Context Manager"
  difficulty="médio"
  initialCode={`import asyncio

# Implement an async context manager class 'AsyncTimer' using
# __aenter__ and __aexit__. It should behave like the Timer
# in Exercise 3 but work inside async functions.

#   async def main():
#       async with AsyncTimer() as t:
#           await asyncio.sleep(0)

<PythonRunner
  title="Async Retry Decorator"
  difficulty="difícil"
  initialCode={`import asyncio
import functools

# Write an async decorator factory 'async_retry(max_attempts, delay)'
# that retries a failing async function up to max_attempts times,
# waiting delay seconds between retries.
#
# If all attempts fail, re-raise the last exception.

def async_retry(max_attempts=3, delay=0):
    def decorator(func):
        @functools.wraps(func)
        async def wrapper(*args, **kwargs):
            # Your code here
            pass
        return wrapper
    return decorator

# Test: this function fails the first 2 times, succeeds on the 3rd

@async_retry(max_attempts=3, delay=0)
async def flaky():
    global attempt_count
    attempt_count += 1
    if attempt_count < 3:
        raise RuntimeError(f"Fail #{attempt_count}")
    return "success"

result = asyncio.run(flaky())
print(f"Result: {result}")
print(f"Attempts needed: {attempt_count}")
