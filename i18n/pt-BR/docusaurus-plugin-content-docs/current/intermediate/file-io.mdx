# Entrada/Saída de Arquivos

Neste módulo você vai aprender como o Python lê e escreve arquivos usando a função embutida `open()`, como manipular dados CSV e JSON, e como gerenciar recursos com segurança usando o **gerenciador de contexto** (instrução `with`). Ao final você terá confiança para ler, escrever e transformar dados baseados em arquivos em Python.

## Objetivos de Aprendizagem

- Abrir arquivos em diferentes modos (`r`, `w`, `a`, `rb`)
- Ler e escrever arquivos de texto com segurança usando gerenciadores de contexto
- Analisar e escrever dados CSV com o módulo `csv`
- Serializar e desserializar JSON com o módulo `json`
- Usar `io.StringIO` para objetos semelhantes a arquivos na memória (compatível com Pyodide)

---

## Teoria

### A Função `open()` e Modos de Arquivo

Python abre arquivos com a função embutida `open()`. O segundo argumento é o **modo**:

| Modo | Significado |
|------|-------------|
| `"r"` | Leitura (padrão) — o arquivo deve existir |
| `"w"` | Escrita — cria ou **sobrescreve** o arquivo |
| `"a"` | Anexar — cria ou **adiciona ao** final |
| `"rb"` / `"wb"` | Leitura / escrita binária |

```python
f = open("data.txt", "w")
f.write("Hello, file!")
f.close()           # sempre feche quando terminar
```

:::tip
Esquecer de chamar `close()` pode corromper arquivos ou vazar descritores de arquivo. Use a instrução `with` (veja abaixo) — ela fecha o arquivo automaticamente.
:::

Consulte [open() — Funções Embutidas](https://docs.python.org/3/library/functions.html#open) para referência completa.

### Gerenciadores de Contexto — Instrução `with`

A instrução `with` garante que o arquivo seja fechado quando o bloco terminar, mesmo que uma exceção ocorra:

```python
with open("data.txt", "w") as f:
    f.write("Hello, file!\n")
    f.write("Second line.\n")
# arquivo é fechado automaticamente aqui
```

Lendo o arquivo de volta:

```python
with open("data.txt", "r") as f:
    content = f.read()          # arquivo inteiro como string
    # — ou —
    lines = f.readlines()       # lista de linhas
    # — ou —
    for line in f:              # iterar linha a linha
        print(line.strip())
```

:::note
No Pyodide (o runtime Python no navegador usado aqui) você pode escrever no sistema de arquivos virtual assim como em uma máquina real. Os arquivos existem apenas durante a sessão da página.
:::

Consulte [Lendo e Escrevendo Arquivos](https://docs.python.org/3/tutorial/inputoutput.html#reading-and-writing-files) para mais detalhes.

### `io.StringIO` — Arquivos na Memória

`io.StringIO` fornece um objeto semelhante a arquivo suportado por uma string na memória. É útil para testar código que espera um arquivo sem tocar no disco:

```python
import io

buffer = io.StringIO()
buffer.write("line one\n")
buffer.write("line two\n")
buffer.seek(0)               # rebobinar para o início
content = buffer.read()
print(content)
```

Consulte [io — Ferramentas de núcleo para trabalhar com streams](https://docs.python.org/3/library/io.html).

### Manipulação de CSV

O módulo `csv` simplifica a leitura e escrita de valores separados por vírgula:

```python
import csv, io

# Escrever CSV em um buffer StringIO
output = io.StringIO()
writer = csv.writer(output)
writer.writerow(["name", "age", "city"])
writer.writerow(["Alice", 30, "London"])
writer.writerow(["Bob", 25, "Paris"])

# Ler de volta
output.seek(0)
reader = csv.DictReader(output)
for row in reader:
    print(row["name"], row["age"])
```

:::tip
Use `csv.DictReader` para obter cada linha como um dicionário com chaves baseadas nos nomes do cabeçalho — muito mais legível do que indexar por número de coluna.
:::

Consulte [csv — Leitura e Escrita de Arquivo CSV](https://docs.python.org/3/library/csv.html).

### Manipulação de JSON

O módulo `json` converte objetos Python em strings JSON e de volta:

```python
import json

data = {"name": "Alice", "scores": [95, 87, 92], "active": True}

# Serializar Python → string JSON
json_str = json.dumps(data, indent=2)
print(json_str)

# Desserializar string JSON → Python
loaded = json.loads(json_str)
print(loaded["name"])        # Alice
print(loaded["scores"][0])   # 95
```

Use `json.dump()` / `json.load()` ao trabalhar com objetos de arquivo reais em vez de strings.

Consulte [json — Codificador e decodificador JSON](https://docs.python.org/3/library/json.html).
