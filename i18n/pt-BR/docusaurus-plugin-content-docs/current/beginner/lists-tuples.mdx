# Listas & Tuplas

Listas e tuplas são os dois principais tipos de **sequência** do Python. Listas são mutáveis e repletas de métodos úteis; tuplas são imutáveis e ideais para coleções fixas de valores. Neste módulo você vai aprender a criar, indexar, fatiar e transformar ambos os tipos, e descobrir o elegante poder das **compreensões de lista**.

## Objetivos de Aprendizagem

- Criar e modificar listas usando indexação, fatiamento e métodos comuns
- Entender a diferença entre listas mutáveis e tuplas imutáveis
- Usar compreensões de lista para construir listas de forma concisa
- Desempacotar sequências em variáveis
- Aplicar funções de ordenação, busca e agregação a sequências

---

## Teoria

### Fundamentos de Listas

Uma lista é uma coleção ordenada e mutável de itens entre colchetes:

```python
fruits = ["apple", "banana", "cherry"]
mixed  = [1, "hello", 3.14, True]  # pode conter qualquer tipo
empty  = []
```

Acesse elementos por índice baseado em zero. Índices negativos contam a partir do fim:

```python
fruits[0]   # "apple"
fruits[-1]  # "cherry"
fruits[1:3] # ["banana", "cherry"]  (fatiamento)
```

### Métodos de Lista

```python
lst = [3, 1, 4, 1, 5]

lst.append(9)         # [3, 1, 4, 1, 5, 9]   — adiciona ao fim
lst.insert(0, 0)      # [0, 3, 1, 4, 1, 5, 9] — insere no índice
lst.remove(1)         # remove a primeira ocorrência de 1
lst.pop()             # remove e retorna o último elemento
lst.pop(0)            # remove e retorna o elemento no índice 0
lst.sort()            # ordena no lugar (crescente)
lst.sort(reverse=True)# ordena decrescente
lst.reverse()         # inverte no lugar
lst.count(1)          # quantas vezes 1 aparece
lst.index(4)          # índice da primeira ocorrência de 4
lst.extend([7, 8])    # adiciona todos os itens de outro iterável
```

:::tip
`sort()` modifica a lista no lugar e retorna `None`. Se você precisar de uma nova lista ordenada, use a função embutida `sorted(lst)`.
:::

Consulte [métodos de lista](https://docs.python.org/3/tutorial/datastructures.html#more-on-lists) na documentação.

### Compreensões de Lista

Uma compreensão de lista é uma forma compacta de construir uma lista a partir de um iterável:

```python
# Forma básica: [expressão for item in iterável]
squares = [x ** 2 for x in range(1, 6)]   # [1, 4, 9, 16, 25]

# Com condição de filtro:
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]

# Aninhada:
pairs = [(x, y) for x in range(3) for y in range(3)]
```

:::note
Compreensões de lista são frequentemente mais rápidas e legíveis do que loops `for` equivalentes com `.append()`. Use-as para transformações simples; fique com loops regulares para lógica complexa.
:::

### Tuplas

Uma tupla é uma sequência ordenada e **imutável** entre parênteses:

```python
point = (3, 4)
rgb   = (255, 128, 0)
single = (42,)   # atenção para a vírgula final — necessária para tuplas de um elemento!
```

Como tuplas não podem ser alteradas após a criação, elas são:
- Seguras para usar como chaves de dicionário
- Ligeiramente mais rápidas e eficientes em memória do que listas
- Uma boa escolha para coleções fixas (coordenadas, registros, etc.)

Tuplas suportam a mesma indexação e fatiamento que listas.

### Desempacotamento

Tanto listas quanto tuplas podem ser **desempacotadas** em variáveis individuais:

```python
x, y = (3, 4)
first, *rest = [1, 2, 3, 4, 5]   # first=1, rest=[2,3,4,5]
a, b, c = "abc"                   # funciona com qualquer iterável
```

Consulte [Tuplas e Sequências](https://docs.python.org/3/tutorial/datastructures.html#tuples-and-sequences) para mais informações.
