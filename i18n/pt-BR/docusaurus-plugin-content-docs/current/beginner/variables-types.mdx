# Variáveis & Tipos

Neste módulo você vai aprender como o Python armazena dados usando **variáveis**, explorar os quatro **tipos de dados** fundamentais, converter entre eles e formatar a saída com **f-strings**. Ao final você se sentirá à vontade para declarar variáveis, raciocinar sobre seus tipos e manipular strings e números em Python.

## Objetivos de Aprendizagem

- Entender variáveis e atribuição em Python
- Conhecer os tipos de dados básicos (`int`, `float`, `str`, `bool`)
- Usar funções de conversão de tipo
- Trabalhar com f-strings para saída de dados

---

## Teoria

### Variáveis

Uma variável em Python é um nome que se refere a um valor armazenado na memória. Você cria uma variável com uma simples **instrução de atribuição** usando o operador `=`:

```python
age = 25
greeting = "Hello"
pi = 3.14159
```

Diferentemente de muitas outras linguagens, Python não exige que você declare um tipo — o tipo é inferido automaticamente a partir do valor atribuído. Você pode inclusive reatribuir uma variável a um tipo completamente diferente depois, embora isso seja geralmente desencorajado por questões de legibilidade.

Os nomes de variáveis devem começar com uma letra ou sublinhado, podem conter letras, dígitos e sublinhados, e são **sensíveis a maiúsculas e minúsculas** (`age` e `Age` são variáveis diferentes). A comunidade Python adota a convenção `snake_case` para nomes de variáveis e funções (ex.: `minha_variavel`, `total_count`).

:::tip
Escolha nomes descritivos. `x = 30` não diz nada ao leitor; `temperatura_celsius = 30` é imediatamente claro.
:::

Para mais detalhes, consulte o [Tutorial Python — Uma Introdução Informal](https://docs.python.org/3/tutorial/introduction.html).

### Tipos de Dados

Python possui quatro tipos embutidos fundamentais que você usará constantemente:

| Tipo    | Exemplo          | Descrição                          |
|---------|------------------|------------------------------------|
| `int`   | `42`, `-7`, `0`  | Números inteiros (precisão ilimitada)|
| `float` | `3.14`, `-0.5`   | Números decimais (ponto flutuante) |
| `str`   | `"hello"`, `'hi'`| Texto entre aspas                  |
| `bool`  | `True`, `False`  | Valores lógicos de verdade         |

Você pode verificar o tipo de qualquer valor com a função embutida `type()`:

```python
type(42)        # <class 'int'>
type(3.14)      # <class 'float'>
type("hello")   # <class 'str'>
type(True)      # <class 'bool'>
```

:::note
Em Python, `bool` é uma subclasse de `int`. `True` equivale a `1` e `False` equivale a `0`, portanto você pode usar booleanos em expressões aritméticas — mas isso não significa que você deva fazê-lo.
:::

Consulte a documentação de [Tipos Embutidos](https://docs.python.org/3/library/stdtypes.html) para uma referência completa.

### Conversão de Tipos

Python fornece funções embutidas para converter entre tipos:

```python
int("42")       # 42       — string para int
float("3.14")   # 3.14     — string para float
str(100)        # "100"    — int para string
bool(0)         # False    — int para bool (0 é falsy)
bool("")        # False    — string vazia é falsy
bool("hello")   # True     — string não vazia é truthy
int(3.9)        # 3        — trunca, NÃO arredonda
```

:::tip
`int()` trunca em direção a zero. Se você precisar arredondar, use `round()`: `round(3.9)` retorna `4`.
:::

Consulte [Funções Embutidas](https://docs.python.org/3/library/functions.html) para a lista completa.

### Formatação de Strings

Python oferece várias formas de construir strings a partir de variáveis. A abordagem moderna e preferida são as **f-strings** (literais de string formatados), disponíveis desde o Python 3.6:

```python
name = "Alice"
age = 30
print(f"Meu nome é {name} e tenho {age} anos.")
```

Você pode colocar qualquer expressão válida dentro das chaves:

```python
print(f"No próximo ano terei {age + 1}.")
print(f"Pi com 2 casas decimais: {3.14159:.2f}")
```

Alternativas mais antigas incluem o método `.format()` e a formatação com `%`:

```python
# .format()
"Olá, {}!".format(name)

# % formatação (legado)
"Olá, %s!" % name
```

:::note
Use f-strings para código novo. Elas são mais rápidas, mais legíveis e menos propensas a erros que as alternativas.
:::

Consulte [Sintaxe de Format String](https://docs.python.org/3/library/string.html#formatstrings) para opções avançadas de formatação.
