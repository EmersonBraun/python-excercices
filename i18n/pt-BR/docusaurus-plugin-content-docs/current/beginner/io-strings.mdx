# Entrada, Saída & Strings

Neste módulo você vai dominar a principal ferramenta de saída do Python — `print()` — e se aprofundar em **strings**: como criá-las, transformá-las com métodos, fatiá-las e formatá-las para exibição. Ao final você será capaz de manipular texto com fluência e produzir saídas bem formatadas.

## Objetivos de Aprendizagem

- Usar `print()` com múltiplos argumentos, separadores e caracteres finais
- Aplicar métodos comuns de string (`.upper()`, `.lower()`, `.strip()`, `.split()`, `.join()`, `.replace()`)
- Fatiar strings com notação de índice
- Usar caracteres de escape dentro de strings
- Entender por que `input()` é substituído por parâmetros de função nos exercícios do navegador

---

## Teoria

### print()

`print()` envia saída para o console. Aceita qualquer número de argumentos separados por vírgulas e, por padrão, os une com um espaço e adiciona uma nova linha ao final:

```python
print("Hello", "world")          # Hello world
print("Hello", "world", sep="-") # Hello-world
print("Sem nova linha", end="")  # fica na mesma linha
print(42, 3.14, True)            # 42 3.14 True
```

Consulte a [documentação de print()](https://docs.python.org/3/library/functions.html#print) para todos os parâmetros.

:::note
Nestes exercícios do navegador, `input()` não está disponível porque o ambiente executa Python via Pyodide (sem terminal interativo). Exercícios que normalmente leriam entrada do usuário aceitam o valor como um **parâmetro de função**.
:::

### Métodos de String

Strings em Python são sequências imutáveis de caracteres. Elas possuem um rico conjunto de métodos embutidos que retornam **novas** strings:

```python
text = "  Hello, World!  "

text.upper()          # "  HELLO, WORLD!  "
text.lower()          # "  hello, world!  "
text.strip()          # "Hello, World!"   — remove espaços no início/fim
text.lstrip()         # "Hello, World!  " — apenas no lado esquerdo
text.rstrip()         # "  Hello, World!" — apenas no lado direito

text.replace("World", "Python")  # "  Hello, Python!  "

csv = "a,b,c,d"
csv.split(",")        # ["a", "b", "c", "d"]
"-".join(["a", "b", "c"])  # "a-b-c"

"hello".startswith("he")  # True
"hello".endswith("lo")    # True
"hello".find("ll")        # 2  (índice da primeira ocorrência)
"hello".count("l")        # 2
```

:::tip
Os métodos podem ser **encadeados**: `"  HELLO  ".strip().lower()` produz `"hello"`.
:::

Consulte [Métodos de String](https://docs.python.org/3/library/stdtypes.html#string-methods) para a lista completa.

### Fatiamento de Strings

Strings suportam acesso baseado em índice e fatiamento usando a sintaxe `[início:fim:passo]`:

```python
s = "Python"
s[0]      # "P"   — primeiro caractere (índice 0)
s[-1]     # "n"   — último caractere
s[1:4]    # "yth" — índices 1, 2, 3 (fim é exclusivo)
s[:3]     # "Pyt" — do início ao índice 3
s[3:]     # "hon" — do índice 3 ao fim
s[::-1]   # "nohtyP" — invertida
s[::2]    # "Pto" — um caractere sim, um não
```

:::note
Python usa **indexação baseada em zero**. Índices negativos contam a partir do fim: `s[-1]` é o último caractere, `s[-2]` é o penúltimo, e assim por diante.
:::

### Caracteres de Escape

Dentro de literais de string você pode incorporar caracteres especiais usando sequências de barra invertida:

| Sequência | Significado     |
|-----------|-----------------|
| `\n`      | Nova linha      |
| `\t`      | Tabulação       |
| `\\`      | `\` literal     |
| `\'`      | Aspas simples   |
| `\"`      | Aspas duplas    |

```python
print("Linha 1\nLinha 2")     # duas linhas
print("Nome:\tAlice")         # tabulação entre label e valor
print("Ela disse \"oi\"")     # aspas incorporadas
```

Como alternativa, use **strings brutas** (`r"..."`) para suprimir todo processamento de escape:

```python
path = r"C:\Users\nome\docs"   # barras invertidas são literais
```
