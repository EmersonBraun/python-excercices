# Funções

Funções são os blocos fundamentais de construção de código reutilizável. Neste módulo você vai aprender a definir funções com `def`, trabalhar com parâmetros e valores de retorno, usar argumentos padrão e assinaturas flexíveis com `*args`/`**kwargs`, escrever funções **lambda** concisas e entender o **escopo** de variáveis. Você também aprenderá a documentar suas funções com **docstrings**.

## Objetivos de Aprendizagem

- Definir e chamar funções usando `def`
- Entender parâmetros posicionais, por palavra-chave e padrão
- Usar `*args` e `**kwargs` para assinaturas de função flexíveis
- Escrever expressões lambda para linhas únicas simples
- Explicar escopo local vs. global
- Escrever docstrings que descrevem o comportamento da função

---

## Teoria

### Definindo Funções

Use a palavra-chave `def`, seguida pelo nome da função, parâmetros entre parênteses e dois-pontos. O corpo é indentado:

```python
def greet(name):
    print(f"Hello, {name}!")

greet("Alice")   # Hello, Alice!
```

Uma função sem uma instrução `return` explícita retorna `None`.

### Valores de Retorno

Use `return` para enviar um valor de volta para quem chamou:

```python
def add(a, b):
    return a + b

result = add(3, 4)   # result = 7
```

Uma função pode retornar **múltiplos valores** como uma tupla:

```python
def min_max(lst):
    return min(lst), max(lst)

lo, hi = min_max([3, 1, 4, 1, 5])   # lo=1, hi=5
```

### Argumentos Padrão

Parâmetros podem ter valores padrão. Os padrões devem vir **depois** dos parâmetros sem padrão:

```python
def power(base, exponent=2):
    return base ** exponent

power(3)      # 9   — usa expoente padrão
power(3, 3)   # 27  — sobrescreve o padrão
```

:::tip
Use padrões imutáveis (números, strings, `None`) — nunca padrões mutáveis como `[]` ou `{}`. Padrões mutáveis são compartilhados entre todas as chamadas, o que gera bugs sutis.
:::

### *args e **kwargs

- `*args` coleta argumentos posicionais extras em uma tupla
- `**kwargs` coleta argumentos por palavra-chave extras em um dicionário

```python
def total(*args):
    return sum(args)

total(1, 2, 3, 4)   # 10

def info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

info(name="Alice", age=30)
```

Consulte [Listas de Argumentos Arbitrários](https://docs.python.org/3/tutorial/controlflow.html#arbitrary-argument-lists) na documentação.

### Expressões Lambda

Um `lambda` cria uma pequena função anônima em uma única expressão:

```python
square = lambda x: x ** 2
square(5)   # 25

# Útil como função de chave:
pairs = [(1, "b"), (2, "a"), (3, "c")]
sorted(pairs, key=lambda p: p[1])  # ordena pelo segundo elemento
```

:::note
Lambdas são limitados a uma única expressão. Para qualquer coisa mais complexa, use um `def` regular.
:::

### Escopo

Python usa a resolução de escopo **LEGB**: Local → Envolvente → Global → Embutido.

```python
x = 10   # global

def show():
    x = 20       # local — NÃO afeta o x global
    print(x)     # 20

show()
print(x)   # 10
```

Use `global` para modificar uma variável global dentro de uma função (geralmente evite isso):

```python
counter = 0
def increment():
    global counter
    counter += 1
```

Consulte [Escopos e Namespaces](https://docs.python.org/3/tutorial/classes.html#python-scopes-and-namespaces).

### Docstrings

Uma docstring é um literal de string colocado como a primeira instrução em uma função. Ela documenta o propósito, os parâmetros e o valor de retorno da função:

```python
def celsius_to_fahrenheit(celsius):
    """Converte uma temperatura de Celsius para Fahrenheit.

    Args:
        celsius (float): Temperatura em graus Celsius.

    Returns:
        float: Temperatura em graus Fahrenheit.
    """
    return celsius * 9 / 5 + 32
```

Acesse uma docstring com `help(celsius_to_fahrenheit)` ou `celsius_to_fahrenheit.__doc__`.

<PythonRunner
  title="memoize"
  difficulty="hard"
  initialCode={`# Write memoize(func) that wraps a function and caches its results.
# When the wrapped function is called with the same arguments a second time,
# return the cached result instead of calling the original function.
#
# Hint: use a dict as the cache, where keys are the arguments.

def memoize(func):
    cache = {}
    def wrapper(*args):
        if args not in cache:
            cache[args] = func(*args)
        return cache[args]
    return wrapper

@memoize
def slow_square(n):
    # Imagine this is expensive

print(slow_square(4))   # 16
print(slow_square(4))   # 16 (from cache)
print(slow_square(5))   # 25
