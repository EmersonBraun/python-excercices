# Python do Zero ao Herói

Bem-vindo ao **Python do Zero ao Herói** — um curso completo e prático que leva você de iniciante absoluto a desenvolvedor Python avançado.

## O Que Você Vai Aprender

- **Iniciante:** Variáveis, tipos de dados, controle de fluxo, loops e E/S básica
- **Intermediário:** Funções, módulos, manipulação de arquivos, tratamento de erros e fundamentos de OOP
- **Avançado:** Decorators, generators, concorrência, padrões de projeto e projetos do mundo real

## Como Usar Este Curso

1. Siga os módulos na ordem, começando pela seção **Iniciante**
2. Complete os exercícios de cada módulo antes de avançar
3. Confira suas soluções com os exemplos fornecidos
4. Construa os projetos para consolidar seu entendimento

## Pré-requisitos

- Um computador com Python 3.10+ instalado
- Um editor de código (VS Code recomendado)
- Familiaridade básica com o uso de um terminal

Pronto para começar? Vá para a seção [Iniciante](/docs/beginner/)!
