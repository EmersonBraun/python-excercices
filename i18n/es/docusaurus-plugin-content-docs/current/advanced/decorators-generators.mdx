# Decoradores y Generadores

En este módulo dominarás dos de las características más poderosas de Python: los **decoradores** que envuelven y mejoran funciones sin modificarlas, y los **generadores** que producen valores de forma perezosa para una iteración eficiente en memoria. Al final podrás escribir decoradores reutilizables, crear secuencias infinitas con `yield`, y usar `itertools` para componer pipelines.

## Objetivos de Aprendizaje

- Entender el patrón decorador y la sintaxis `@`
- Escribir decoradores con y sin argumentos
- Usar `functools.wraps` para preservar metadatos
- Crear funciones generadoras usando `yield`
- Escribir expresiones generadoras
- Combinar generadores con `itertools`

---

## Teoría

### Decoradores

Un **decorador** es una función que toma otra función como argumento, la envuelve con comportamiento adicional, y devuelve la versión envuelta. La sintaxis `@` es una abreviatura de `func = decorator(func)`:

```python
import functools

def shout(func):
    @functools.wraps(func)  # preserves __name__, __doc__, etc.
    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        return str(result).upper()
    return wrapper

@shout
def greet(name):
    return f"hello, {name}"

greet("alice")   # "HELLO, ALICE"
```

:::tip
Siempre aplica `@functools.wraps(func)` a tu función interna `wrapper`. Sin él, la función decorada pierde su `__name__` y `__doc__` originales, lo que rompe la introspección y la depuración.
:::

### Decoradores con Argumentos

Para pasar argumentos a un decorador, se agrega una tercera capa — una función de fábrica que devuelve el decorador real:

```python
def repeat(n):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(n):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def say(msg):
    print(msg)

say("hi")   # prints "hi" three times
```

### Decoradores de Clase

Las clases también pueden ser decoradores si implementan `__call__`:

```python
class Counter:
    def __init__(self, func):
        functools.update_wrapper(self, func)
        self.func = func
        self.calls = 0

    def __call__(self, *args, **kwargs):
        self.calls += 1
        return self.func(*args, **kwargs)

@Counter
def add(a, b):
    return a + b

add(1, 2)
add(3, 4)
print(add.calls)   # 2
```

Consulta [Decoradores](https://docs.python.org/3/glossary.html#term-decorator) en el glosario de Python.

### Generadores

Una **función generadora** usa `yield` en lugar de `return`. Al llamarla devuelve un **objeto generador** que produce valores de uno en uno — calculando cada valor solo cuando se solicita (evaluación perezosa):

```python
def count_up(start, stop):
    n = start
    while n <= stop:
        yield n
        n += 1

for x in count_up(1, 5):
    print(x)   # 1, 2, 3, 4, 5
```

Los generadores son ideales para secuencias grandes o infinitas porque nunca mantienen todos los valores en memoria a la vez.

### Expresiones Generadoras

Como las comprensiones de listas pero con `()` — crean un generador sin definir una función:

```python
squares = (x**2 for x in range(1_000_000))   # no memory spike
total = sum(squares)
```

### Fundamentos de itertools

El módulo `itertools` proporciona herramientas componibles para pipelines de generadores:

| Función | Descripción |
|----------|-------------|
| `itertools.count(start)` | Contador infinito |
| `itertools.cycle(iterable)` | Repite el iterable indefinidamente |
| `itertools.islice(gen, n)` | Toma los primeros n elementos |
| `itertools.takewhile(pred, gen)` | Genera mientras el predicado sea True |
| `itertools.dropwhile(pred, gen)` | Omite mientras el predicado sea True |
| `itertools.chain(*iters)` | Concatena iterables |

```python
import itertools

fib_under_100 = list(itertools.takewhile(lambda x: x < 100, fibonacci_gen()))
```

Consulta [itertools — Funciones que crean iteradores para bucles eficientes](https://docs.python.org/3/library/itertools.html).
