# Programación Asíncrona y Gestores de Contexto

En este módulo aprenderás cómo Python maneja la **programación asíncrona** con `async`/`await` y `asyncio`, cómo construir y usar **gestores de contexto** con la instrucción `with`, y cómo agregar **anotaciones de tipo** para hacer que tu código sea autodocumentado. Al final podrás escribir programas async concurrentes, crear gestores de contexto personalizados y anotar firmas de funciones.

## Objetivos de Aprendizaje

- Escribir funciones `async def` y `await` coroutines
- Usar `asyncio.gather` para ejecutar tareas de forma concurrente
- Implementar gestores de contexto con `__enter__`/`__exit__`
- Construir gestores de contexto con `@contextmanager`
- Agregar anotaciones de tipo a funciones y variables

---

## Teoría

### Fundamentos de async / await

La biblioteca `asyncio` de Python permite **multitarea cooperativa**: mientras una coroutine espera E/S, otras coroutines pueden ejecutarse. Defines una coroutine con `async def` y la pausas con `await`:

```python
import asyncio

async def greet(name, delay):
    await asyncio.sleep(delay)   # yields control while waiting
    print(f"Hello, {name}!")

asyncio.run(greet("Alice", 1))
```

:::note
En Pyodide (el runtime de Python en el navegador usado para estos ejercicios), usa `asyncio.run()` para ejecutar código async desde un contexto sincrónico. Pyodide soporta `runPythonAsync` internamente.
:::

### asyncio.gather — Tareas Concurrentes

`asyncio.gather(*coroutines)` ejecuta múltiples coroutines **de forma concurrente** y espera a todas:

```python
async def main():
    # These two run at the same time — total ~1s, not ~2s
    await asyncio.gather(
        greet("Alice", 0.5),
        greet("Bob", 1.0),
    )

asyncio.run(main())
```

Consulta [asyncio — E/S Asíncrona](https://docs.python.org/3/library/asyncio.html).

### Gestores de Contexto — Instrucción `with`

La instrucción `with` garantiza la configuración y el desmontaje, incluso si ocurre una excepción. Cualquier objeto que implemente `__enter__` y `__exit__` puede usarse:

```python
class ManagedResource:
    def __enter__(self):
        print("Acquiring resource")
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        print("Releasing resource")
        return False   # False = don't suppress exceptions

with ManagedResource() as r:
    print("Using resource")
```

### `contextlib.contextmanager`

El decorador `@contextmanager` te permite escribir gestores de contexto como funciones generadoras — más limpio para casos simples:

```python
from contextlib import contextmanager

@contextmanager
def timer(label="block"):
    import time
    start = time.perf_counter()
    try:
        yield          # code inside the `with` block runs here
    finally:
        elapsed = time.perf_counter() - start
        print(f"{label} took {elapsed:.4f}s")

with timer("my work"):
    sum(range(1_000_000))
```

Consulta [contextlib](https://docs.python.org/3/library/contextlib.html).

### Anotaciones de Tipo

Las anotaciones de tipo de Python son sugerencias para humanos y herramientas — **no** afectan el comportamiento en tiempo de ejecución:

```python
def greet(name: str, times: int = 1) -> str:
    return (f"Hello, {name}!\n" * times).strip()

age: int = 30
scores: list[int] = [95, 87, 92]
lookup: dict[str, int] = {"a": 1, "b": 2}
```

Usa `from typing import Optional, Union, Callable` para tipos más complejos (Python 3.9 e inferior requieren `from typing import List, Dict`).

Consulta [typing — Soporte para sugerencias de tipo](https://docs.python.org/3/library/typing.html).

### Ejercicio 6 — Gestor de Contexto Async

<PythonRunner
  title="Async Context Manager"
  difficulty="medio"
  initialCode={`import asyncio

# Implement an async context manager class 'AsyncTimer' using
# __aenter__ and __aexit__. It should behave like the Timer
# in Exercise 3 but work inside async functions.
#
# Usage:
#   async def main():
#       async with AsyncTimer() as t:
#           await asyncio.sleep(0)
#       print(t.elapsed)

import time

class AsyncTimer:
    def __init__(self):
        self.elapsed = 0.0

    async def __aenter__(self):
        self._start = time.perf_counter()

        return False

        total = sum(range(100_000))
    print(f"Elapsed: {t.elapsed:.6f}s")
    print(f"elapsed > 0: {t.elapsed > 0}")

print(f"Final elapsed: {elapsed:.6f}s")
