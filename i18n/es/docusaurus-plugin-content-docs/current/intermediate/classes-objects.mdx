# Clases y Objetos

En este módulo aprenderás cómo Python implementa la **Programación Orientada a Objetos** (POO) a través de clases, instancias y métodos. Definirás clases con `__init__`, gestionarás variables de instancia y de clase, usarás `self`, y expondrás acceso seguro a atributos con `@property`. Al final podrás modelar entidades del mundo real como clases Python.

## Objetivos de Aprendizaje

- Definir una clase e instanciar objetos
- Escribir `__init__` para inicializar atributos de instancia
- Distinguir métodos de instancia, métodos de clase y métodos estáticos
- Entender la diferencia entre variables de instancia y variables de clase
- Usar `@property` y setters para encapsular el acceso a atributos

## Teoría

### Definir una Clase

Una clase es un plano para crear objetos. Se define con la palabra clave `class`:

```python
class Dog:
    species = "Canis familiaris"   # class variable — shared by all instances

    def __init__(self, name, age):
        self.name = name           # instance variable — unique per object
        self.age = age

    def bark(self):
        return f"{self.name} says: Woof!"

rex = Dog("Rex", 3)
print(rex.bark())            # Rex says: Woof!
print(rex.species)           # Canis familiaris
print(Dog.species)           # Canis familiaris
```

:::tip
Usa `ClassName` en `PascalCase` (también llamado `UpperCamelCase`). Las instancias y métodos usan `snake_case`.
:::

Consulta [Clases — Tutorial de Python](https://docs.python.org/3/tutorial/classes.html).

### `__init__` y `self`

`__init__` es el **inicializador** (informalmente llamado el constructor). Se llama automáticamente cuando creas una nueva instancia. El primer parámetro (`self`) es una referencia al objeto recién creado:

```python
class Circle:
    PI = 3.14159

    def __init__(self, radius):
        if radius <= 0:
            raise ValueError("Radius must be positive")
        self.radius = radius

    def area(self):
        return Circle.PI * self.radius ** 2

    def perimeter(self):
        return 2 * Circle.PI * self.radius
```

:::note
`self` es solo una convención de nombre — Python pasa la instancia como primer argumento automáticamente. Cualquier otro nombre funciona, pero `self` es el estándar universal.
:::

### Variables de Instancia vs. Variables de Clase

| | Variable de instancia | Variable de clase |
|-|-----------------------|-------------------|
| Definida en | `__init__` (normalmente) | Cuerpo de la clase (fuera de métodos) |
| Almacenada en | La instancia | La clase |
| Alcance | Única para cada objeto | Compartida entre todas las instancias |

```python
class Counter:
    count = 0          # class variable

    def __init__(self):
        Counter.count += 1
        self.id = Counter.count   # instance variable

a = Counter()
b = Counter()
print(Counter.count)  # 2
print(a.id, b.id)     # 1 2
```

### `@property`

`@property` convierte un método en un atributo de solo lectura, permitiéndote agregar validación o valores calculados sin cambiar la interfaz externa:

```python
class Temperature:
    def __init__(self, celsius):
        self._celsius = celsius

    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("Temperature below absolute zero!")
        self._celsius = value

    @property
    def fahrenheit(self):
        return self._celsius * 9 / 5 + 32

t = Temperature(100)
print(t.fahrenheit)   # 212.0
t.celsius = 0
print(t.fahrenheit)   # 32.0
```

:::tip
Prefija los atributos "privados" con un guión bajo (`_celsius`) por convención. Python no aplica control de acceso, pero el guión bajo señala "no toques esto directamente".
:::

Consulta [property — Funciones Integradas](https://docs.python.org/3/library/functions.html#property).

### `@classmethod` y `@staticmethod`

```python
class Date:
    def __init__(self, year, month, day):
        self.year, self.month, self.day = year, month, day

    @classmethod
    def from_string(cls, date_str):
        year, month, day = map(int, date_str.split("-"))
        return cls(year, month, day)   # creates an instance

    @staticmethod
    def is_leap_year(year):
        return year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)

d = Date.from_string("2024-03-15")
print(Date.is_leap_year(2024))  # True
```
