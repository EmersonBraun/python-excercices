# Funciones

Las funciones son los bloques de construcción fundamentales del código reutilizable. En este módulo aprenderás a definir funciones con `def`, trabajar con parámetros y valores de retorno, usar argumentos predeterminados y firmas flexibles con `*args`/`**kwargs`, escribir funciones **lambda** concisas, y entender el **alcance** de las variables. También aprenderás a documentar tus funciones con **docstrings**.

## Objetivos de Aprendizaje

- Definir y llamar funciones usando `def`
- Entender parámetros posicionales, de palabra clave y predeterminados
- Usar `*args` y `**kwargs` para firmas de funciones flexibles
- Escribir expresiones lambda para líneas simples
- Explicar el alcance local vs. global
- Escribir docstrings que describan el comportamiento de la función

---

## Teoría

### Definición de Funciones

Usa la palabra clave `def`, seguida del nombre de la función, los parámetros entre paréntesis y dos puntos. El cuerpo está indentado:

```python
def greet(name):
    print(f"Hello, {name}!")

greet("Alice")   # Hello, Alice!
```

Una función sin una instrucción `return` explícita devuelve `None`.

### Valores de Retorno

Usa `return` para enviar un valor de regreso al que llama:

```python
def add(a, b):
    return a + b

result = add(3, 4)   # result = 7
```

Una función puede devolver **múltiples valores** como una tupla:

```python
def min_max(lst):
    return min(lst), max(lst)

lo, hi = min_max([3, 1, 4, 1, 5])   # lo=1, hi=5
```

### Argumentos Predeterminados

Los parámetros pueden tener valores predeterminados. Los valores predeterminados deben venir **después** de los parámetros sin valor predeterminado:

```python
def power(base, exponent=2):
    return base ** exponent

power(3)      # 9   — uses default exponent
power(3, 3)   # 27  — overrides default
```

:::tip
Usa valores predeterminados inmutables (números, cadenas, `None`) — nunca predeterminados mutables como `[]` o `{}`. Los predeterminados mutables se comparten entre todas las llamadas, lo que lleva a errores sutiles.
:::

### *args y **kwargs

- `*args` recopila argumentos posicionales adicionales en una tupla
- `**kwargs` recopila argumentos de palabra clave adicionales en un diccionario

```python
def total(*args):
    return sum(args)

total(1, 2, 3, 4)   # 10

def info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

info(name="Alice", age=30)
```

Consulta [Listas de Argumentos Arbitrarios](https://docs.python.org/3/tutorial/controlflow.html#arbitrary-argument-lists) en la documentación.

### Expresiones Lambda

Un `lambda` crea una pequeña función anónima en una sola expresión:

```python
square = lambda x: x ** 2
square(5)   # 25

# Useful as a key function:
pairs = [(1, "b"), (2, "a"), (3, "c")]
sorted(pairs, key=lambda p: p[1])  # sort by second element
```

:::note
Los lambdas están limitados a una sola expresión. Para algo más complejo, usa un `def` regular.
:::

### Alcance

Python usa la resolución de alcance **LEGB**: Local → Envolvente → Global → Integrado.

```python
x = 10   # global

def show():
    x = 20       # local — does NOT affect the global x
    print(x)     # 20

show()
print(x)   # 10
```

Usa `global` para modificar una variable global dentro de una función (generalmente evita esto):

```python
counter = 0
def increment():
    global counter
    counter += 1
```

Consulta [Alcances y Espacios de Nombres](https://docs.python.org/3/tutorial/classes.html#python-scopes-and-namespaces).

### Docstrings

Un docstring es un literal de cadena colocado como la primera instrucción en una función. Documenta el propósito, los parámetros y el valor de retorno de la función:

```python
def celsius_to_fahrenheit(celsius):
    """Convert a temperature from Celsius to Fahrenheit.

    Args:
        celsius (float): Temperature in degrees Celsius.

    Returns:
        float: Temperature in degrees Fahrenheit.
    """
    return celsius * 9 / 5 + 32
```

Accede a un docstring con `help(celsius_to_fahrenheit)` o `celsius_to_fahrenheit.__doc__`.

  initialCode={`# Write memoize(func) that wraps a function and caches its results.
# When the wrapped function is called with the same arguments a second time,

def memoize(func):
    cache = {}
    def wrapper(*args):
        if args not in cache:

        return cache[args]
    return wrapper

def slow_square(n):
