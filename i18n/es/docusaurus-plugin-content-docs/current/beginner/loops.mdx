# Bucles e Iteración

Los bucles te permiten repetir un bloque de código sin copiarlo y pegarlo. En este módulo aprenderás las dos construcciones de bucle de Python — `for` y `while` — junto con las herramientas que hacen la iteración más expresiva: `range()`, `enumerate()`, `break`, `continue` y bucles anidados.

## Objetivos de Aprendizaje

- Escribir bucles `for` sobre secuencias y objetos `range()`
- Escribir bucles `while` con condiciones de terminación correctas
- Usar `break` para salir de un bucle antes de tiempo y `continue` para saltar una iteración
- Usar `enumerate()` para iterar con un índice
- Construir bucles anidados para problemas multidimensionales

---

## Teoría

### Bucles for

Un bucle `for` itera sobre cualquier **iterable** — una lista, cadena, tupla, rango, etc.:

```python
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

for char in "Python":
    print(char)
```

:::tip
La variable del bucle (`fruit`, `char`) es solo una variable regular. Puedes llamarla como quieras, pero elige algo con significado.
:::

### range()

`range()` genera una secuencia de enteros sin almacenarlos todos en memoria:

```python
range(5)          # 0, 1, 2, 3, 4
range(1, 6)       # 1, 2, 3, 4, 5
range(0, 10, 2)   # 0, 2, 4, 6, 8  (step of 2)
range(10, 0, -1)  # 10, 9, ..., 1  (count down)
```

Consulta [range()](https://docs.python.org/3/library/stdtypes.html#ranges) en la documentación.

### Bucles while

Un bucle `while` se repite mientras su condición sea `True`:

```python
count = 0
while count < 5:
    print(count)
    count += 1
```

:::note
Siempre asegúrate de que la condición del bucle eventualmente se vuelva `False`, de lo contrario crearás un **bucle infinito**.
:::

### break y continue

- `break` — sale inmediatamente del bucle que lo contiene
- `continue` — salta el resto de la iteración actual y pasa a la siguiente

```python
for n in range(10):
    if n == 5:
        break       # stop when n reaches 5
    if n % 2 == 0:
        continue    # skip even numbers
    print(n)        # prints 1, 3
```

Consulta [break y continue](https://docs.python.org/3/tutorial/controlflow.html#break-and-continue-statements) en el tutorial.

### enumerate()

Cuando necesitas tanto el índice como el valor durante un bucle, usa `enumerate()`:

```python
colors = ["red", "green", "blue"]
for i, color in enumerate(colors):
    print(f"{i}: {color}")
# 0: red
# 1: green
# 2: blue

# Start counting from 1:
for i, color in enumerate(colors, start=1):
    print(f"{i}. {color}")
```

### Bucles Anidados

Puedes colocar un bucle dentro de otro. El bucle interior completa todas sus iteraciones por cada iteración individual del bucle exterior:

```python
for row in range(3):
    for col in range(3):
        print(f"({row},{col})", end=" ")
    print()   # newline after each row
```

:::tip
Cuidado con el rendimiento: si ambos bucles se ejecutan `n` veces, el cuerpo se ejecuta `n²` veces.
:::

Consulta el [Tutorial de Python — Instrucciones for](https://docs.python.org/3/tutorial/controlflow.html#for-statements) para más información.
