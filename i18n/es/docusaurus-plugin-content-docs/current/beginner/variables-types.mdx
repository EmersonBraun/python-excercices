# Variables y Tipos

En este módulo aprenderás cómo Python almacena datos usando **variables**, explorarás los cuatro **tipos de datos** fundamentales, cómo convertir entre ellos y cómo formatear la salida con **f-strings**. Al final te sentirás cómodo declarando variables, razonando sobre sus tipos y manipulando cadenas y números en Python.

## Objetivos de Aprendizaje

- Entender las variables de Python y la asignación
- Conocer los tipos de datos básicos (`int`, `float`, `str`, `bool`)
- Usar funciones de conversión de tipos
- Trabajar con f-strings para la salida

---

## Teoría

### Variables

Una variable en Python es un nombre que hace referencia a un valor almacenado en memoria. Creas una variable con una simple **instrucción de asignación** usando el operador `=`:

```python
age = 25
greeting = "Hello"
pi = 3.14159
```

A diferencia de muchos otros lenguajes, Python no requiere que declares un tipo — el tipo se infiere automáticamente a partir del valor que asignas. Incluso puedes reasignar una variable a un tipo completamente diferente más adelante, aunque hacerlo generalmente no se recomienda por legibilidad.

Los nombres de variables deben comenzar con una letra o guión bajo, pueden contener letras, dígitos y guiones bajos, y son **sensibles a mayúsculas** (`age` y `Age` son variables diferentes). La comunidad Python sigue la convención `snake_case` para nombres de variables y funciones (p.ej. `mi_variable`, `total_cuenta`).

:::tip
Elige nombres descriptivos. `x = 30` no le dice nada al lector; `temperatura_celsius = 30` es inmediatamente claro.
:::

Para más detalles, consulta el [Tutorial de Python — Una Introducción Informal](https://docs.python.org/3/tutorial/introduction.html).

### Tipos de Datos

Python tiene cuatro tipos integrados fundamentales que usarás constantemente:

| Tipo    | Ejemplo          | Descripción                          |
|---------|------------------|--------------------------------------|
| `int`   | `42`, `-7`, `0`  | Números enteros (precisión ilimitada) |
| `float` | `3.14`, `-0.5`   | Números decimales (punto flotante)   |
| `str`   | `"hello"`, `'hi'`| Texto entre comillas                 |
| `bool`  | `True`, `False`  | Valores lógicos de verdad            |

Puedes verificar el tipo de cualquier valor con la función integrada `type()`:

```python
type(42)        # <class 'int'>
type(3.14)      # <class 'float'>
type("hello")   # <class 'str'>
type(True)      # <class 'bool'>
```

:::note
En Python, `bool` es una subclase de `int`. `True` equivale a `1` y `False` equivale a `0`, por lo que puedes usar booleanos en expresiones aritméticas — pero eso no significa que debas hacerlo.
:::

Consulta la documentación de [Tipos Integrados](https://docs.python.org/3/library/stdtypes.html) para una referencia completa.

### Conversión de Tipos

Python provee funciones integradas para convertir entre tipos:

```python
int("42")       # 42       — string to int
float("3.14")   # 3.14     — string to float
str(100)        # "100"    — int to string
bool(0)         # False    — int to bool (0 is falsy)
bool("")        # False    — empty string is falsy
bool("hello")   # True     — non-empty string is truthy
int(3.9)        # 3        — truncates, does NOT round
```

:::tip
`int()` trunca hacia cero. Si necesitas redondear, usa `round()` en su lugar: `round(3.9)` devuelve `4`.
:::

Consulta [Funciones Integradas](https://docs.python.org/3/library/functions.html) para la lista completa.

### Formato de Cadenas

Python ofrece varias formas de construir cadenas a partir de variables. El enfoque moderno y preferido son las **f-strings** (literales de cadenas formateadas), disponibles desde Python 3.6:

```python
name = "Alice"
age = 30
print(f"My name is {name} and I am {age} years old.")
```

Puedes poner cualquier expresión válida dentro de las llaves:

```python
print(f"Next year I will be {age + 1}.")
print(f"Pi to 2 decimals: {3.14159:.2f}")
```

Las alternativas más antiguas incluyen el método `.format()` y el formato con `%`:

```python
# .format()
"Hello, {}!".format(name)

# % formatting (legacy)
"Hello, %s!" % name
```

:::note
Usa f-strings para código nuevo. Son más rápidas, más legibles y menos propensas a errores que las alternativas.
:::

Consulta [Sintaxis de Cadenas de Formato](https://docs.python.org/3/library/string.html#formatstrings) para opciones de formato avanzadas.
