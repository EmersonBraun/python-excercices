# Listas y Tuplas

Las listas y las tuplas son los dos tipos de **secuencia** principales de Python. Las listas son mutables y están repletas de métodos útiles; las tuplas son inmutables e ideales para colecciones fijas de valores. En este módulo aprenderás a crear, indexar, segmentar y transformar ambos tipos, y descubrirás el poder elegante de las **comprensiones de listas**.

## Objetivos de Aprendizaje

- Crear y modificar listas usando indexación, segmentación y métodos comunes
- Entender la diferencia entre listas mutables y tuplas inmutables
- Usar comprensiones de listas para construir listas de forma concisa
- Desempaquetar secuencias en variables
- Aplicar funciones de ordenamiento, búsqueda y agregación a secuencias

---

## Teoría

### Fundamentos de Listas

Una lista es una colección ordenada y mutable de elementos entre corchetes:

```python
fruits = ["apple", "banana", "cherry"]
mixed  = [1, "hello", 3.14, True]  # can hold any types
empty  = []
```

Accede a los elementos por índice basado en cero. Los índices negativos cuentan desde el final:

```python
fruits[0]   # "apple"
fruits[-1]  # "cherry"
fruits[1:3] # ["banana", "cherry"]  (slice)
```

### Métodos de Listas

```python
lst = [3, 1, 4, 1, 5]

lst.append(9)         # [3, 1, 4, 1, 5, 9]   — add to end
lst.insert(0, 0)      # [0, 3, 1, 4, 1, 5, 9] — insert at index
lst.remove(1)         # removes first occurrence of 1
lst.pop()             # removes and returns last element
lst.pop(0)            # removes and returns element at index 0
lst.sort()            # sorts in-place (ascending)
lst.sort(reverse=True)# sorts descending
lst.reverse()         # reverses in-place
lst.count(1)          # how many times 1 appears
lst.index(4)          # index of first occurrence of 4
lst.extend([7, 8])    # append all items from another iterable
```

:::tip
`sort()` modifica la lista en su lugar y devuelve `None`. Si necesitas una nueva lista ordenada, usa el integrado `sorted(lst)` en su lugar.
:::

Consulta [métodos de lista](https://docs.python.org/3/tutorial/datastructures.html#more-on-lists) en la documentación.

### Comprensiones de Listas

Una comprensión de lista es una forma compacta de construir una lista a partir de un iterable:

```python
# Basic form: [expression for item in iterable]
squares = [x ** 2 for x in range(1, 6)]   # [1, 4, 9, 16, 25]

# With a filter condition:
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]

# Nested:
pairs = [(x, y) for x in range(3) for y in range(3)]
```

:::note
Las comprensiones de listas son a menudo más rápidas y legibles que los bucles `for` equivalentes con `.append()`. Úsalas para transformaciones simples; sigue con bucles regulares para lógica compleja.
:::

### Tuplas

Una tupla es una secuencia ordenada e **inmutable** entre paréntesis:

```python
point = (3, 4)
rgb   = (255, 128, 0)
single = (42,)   # note the trailing comma — required for single-element tuples!
```

Como las tuplas no se pueden cambiar después de su creación, son:
- Seguras para usar como claves de diccionario
- Ligeramente más rápidas y eficientes en memoria que las listas
- Una buena opción para colecciones fijas (coordenadas, registros, etc.)

Las tuplas admiten la misma indexación y segmentación que las listas.

### Desempaquetado

Tanto las listas como las tuplas pueden **desempaquetarse** en variables individuales:

```python
x, y = (3, 4)
first, *rest = [1, 2, 3, 4, 5]   # first=1, rest=[2,3,4,5]
a, b, c = "abc"                   # works on any iterable
```

Consulta [Tuplas y Secuencias](https://docs.python.org/3/tutorial/datastructures.html#tuples-and-sequences) para más información.
