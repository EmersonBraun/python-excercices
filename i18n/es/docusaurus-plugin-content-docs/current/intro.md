# Python de Cero a Héroe

Bienvenido a **Python de Cero a Héroe** — un curso completo y práctico que te lleva desde principiante absoluto hasta desarrollador Python avanzado.

## Qué Aprenderás

- **Principiante:** Variables, tipos de datos, flujo de control, bucles y E/S básica
- **Intermedio:** Funciones, módulos, manejo de archivos, manejo de errores y fundamentos de POO
- **Avanzado:** Decoradores, generadores, concurrencia, patrones de diseño y proyectos del mundo real

## Cómo Usar Este Curso

1. Sigue los módulos en orden, comenzando con la sección **Principiante**
2. Completa los ejercicios de cada módulo antes de continuar
3. Compara tus soluciones con los ejemplos proporcionados
4. Construye los proyectos para consolidar tu comprensión

## Requisitos Previos

- Una computadora con Python 3.10+ instalado
- Un editor de código (se recomienda VS Code)
- Familiaridad básica con el uso de una terminal

¿Listo para empezar? ¡Ve a la sección [Principiante](/docs/beginner/)!
