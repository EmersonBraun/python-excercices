Herança & Métodos Dunder

Neste módulo você vai aprender como o sistema de herança do Python permite que classes compartilhem e estendam comportamentos, e como os métodos dunder (duplo sublinhado) permitem integrar seus objetos perfeitamente à linguagem Python — tornando-os imprimíveis, comparáveis e iteráveis. Ao final você será capaz de projetar hierarquias de classes limpas e escrever objetos Pythônicos que funcionam naturalmente com funções e operadores embutidos.

Objetivos de Aprendizagem​

  • Usar super() para chamar métodos da classe pai
  • Configurar herança simples e múltipla
  • Entender a Ordem de Resolução de Métodos (MRO) do Python
  • Implementar __str__ e __repr__ para saída legível
  • Usar __eq__, __lt__ e outros dunders de comparação
  • Sobrecarregar operadores com __add__, __mul__, etc.
  • Fazer objetos funcionarem com len() e indexação via __len__ e __getitem__

Teoria​

super() e Herança Simples​

super() fornece um proxy que delega chamadas de método à classe pai, garantindo cadeias de inicialização corretas:

class Animal:
    def __init__(self, name, sound):
        self.name = name
        self.sound = sound

    def speak(self):
        return f"{self.name} says {self.sound}"

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name, sound="Woof")  # chama __init__ do pai
        self.breed = breed

    def fetch(self):
        return f"{self.name} fetches the ball!"

d = Dog("Rex", "Labrador")
print(d.speak())   # Rex says Woof
print(d.fetch())   # Rex fetches the ball!
dica

Sempre chame super().__init__() no __init__ da sua subclasse quando o pai tiver estado para inicializar. Esquecer disso deixa os atributos do pai indefinidos.

Herança Múltipla e MRO​

Python suporta herança múltipla. A Ordem de Resolução de Métodos (MRO) define qual classe é pesquisada primeiro ao buscar um atributo:

class A:
    def hello(self):
        return "Hello from A"

class B(A):
    def hello(self):
        return "Hello from B"

class C(A):
    def hello(self):
        return "Hello from C"

class D(B, C):    # herda de B e C
    pass

print(D().hello())       # Hello from B  (B vem antes de C no MRO)
print(D.__mro__)         # (D, B, C, A, object)

Python usa o algoritmo de linearização C3 para calcular o MRO. O atributo __mro__ e o método ClassName.mro() permitem inspecioná-lo.

nota

A herança múltipla é poderosa, mas pode tornar o código difícil de seguir. Use-a deliberadamente — padrões comuns incluem mixins (classes pequenas que adicionam um único comportamento).

__str__ e __repr__​

  • __str__ é chamado por str() e print() — destinado à saída legível por humanos.
  • __repr__ é chamado por repr() e é o fallback quando __str__ não está definido — destinado a desenvolvedores e depuração.
class Point:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __repr__(self):
        return f"Point({self.x}, {self.y})"

    def __str__(self):
        return f"({self.x}, {self.y})"

p = Point(3, 4)
print(str(p))    # (3, 4)
print(repr(p))   # Point(3, 4)
dica

Implemente __repr__ primeiro — é mais importante para depuração. __str__ usa __repr__ como padrão quando não está explicitamente definido.

Métodos Dunder de Comparação​

Implemente estes para suportar operadores de comparação:

DunderOperador
__eq__==
__ne__!=
__lt__<
__le__<=
__gt__>
__ge__>=
from functools import total_ordering

@total_ordering
class Version:
    def __init__(self, major, minor):
        self.major, self.minor = major, minor

    def __eq__(self, other):
        return (self.major, self.minor) == (other.major, other.minor)

    def __lt__(self, other):
        return (self.major, self.minor) < (other.major, other.minor)

@total_ordering preenche os métodos de comparação restantes a partir de apenas __eq__ e __lt__. Consulte functools.total_ordering.

__len__ e __getitem__​

Estes fazem objetos funcionarem com len() e indexação por colchetes obj[i]:

class Playlist:
    def __init__(self):
        self._songs = []

    def add(self, song):
        self._songs.append(song)

    def __len__(self):
        return len(self._songs)

    def __getitem__(self, index):
        return self._songs[index]

pl = Playlist()
pl.add("Song A"); pl.add("Song B")
print(len(pl))    # 2
print(pl[0])      # Song A

Sobrecarga de Operadores​

class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, scalar):
        return Vector(self.x * scalar, self.y * scalar)

    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

v1 = Vector(1, 2)
v2 = Vector(3, 4)
print(v1 + v2)      # Vector(4, 6)
print(v1 * 3)       # Vector(3, 6)
