Classes & Objetos

Neste módulo você vai aprender como o Python implementa a Programação Orientada a Objetos (OOP) através de classes, instâncias e métodos. Você vai definir classes com __init__, gerenciar variáveis de instância e de classe, usar self e expor acesso seguro a atributos com @property. Ao final você será capaz de modelar entidades do mundo real como classes Python.

Objetivos de Aprendizagem​

  • Definir uma classe e instanciar objetos
  • Escrever __init__ para inicializar atributos de instância
  • Distinguir métodos de instância, métodos de classe e métodos estáticos
  • Entender a diferença entre variáveis de instância e variáveis de classe
  • Usar @property e setters para encapsular o acesso a atributos

Teoria​

Definindo uma Classe​

Uma classe é um molde para objetos. Você a define com a palavra-chave class:

class Dog:
    species = "Canis familiaris"   # variável de classe — compartilhada por todas as instâncias

    def __init__(self, name, age):
        self.name = name           # variável de instância — única por objeto
        self.age = age

    def bark(self):
        return f"{self.name} says: Woof!"

rex = Dog("Rex", 3)
print(rex.bark())            # Rex says: Woof!
print(rex.species)           # Canis familiaris
print(Dog.species)           # Canis familiaris
dica

Use NomeDaClasse em PascalCase (também chamado UpperCamelCase). Instâncias e métodos usam snake_case.

Consulte Classes — Tutorial Python.

__init__ e self​

__init__ é o inicializador (informalmente chamado de construtor). É chamado automaticamente quando você cria uma nova instância. O primeiro parâmetro (self) é uma referência ao objeto recém-criado:

class Circle:
    PI = 3.14159

    def __init__(self, radius):
        if radius <= 0:
            raise ValueError("Radius must be positive")
        self.radius = radius

    def area(self):
        return Circle.PI * self.radius ** 2

    def perimeter(self):
        return 2 * Circle.PI * self.radius
nota

self é apenas uma convenção de nomenclatura — o Python passa a instância como o primeiro argumento automaticamente. Qualquer outro nome funciona, mas self é o padrão universal.

Variáveis de Instância vs. Variáveis de Classe​

Variável de instânciaVariável de classe
Definida em__init__ (geralmente)Corpo da classe (fora dos métodos)
Armazenada noNa instânciaNa classe
EscopoÚnica para cada objetoCompartilhada por todas as instâncias
class Counter:
    count = 0          # variável de classe

    def __init__(self):
        Counter.count += 1
        self.id = Counter.count   # variável de instância

a = Counter()
b = Counter()
print(Counter.count)  # 2
print(a.id, b.id)     # 1 2

@property​

@property transforma um método em um atributo somente leitura, permitindo que você adicione validação ou valores computados sem alterar a interface externa:

class Temperature:
    def __init__(self, celsius):
        self._celsius = celsius

    @property
    def celsius(self):
        return self._celsius

    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("Temperature below absolute zero!")
        self._celsius = value

    @property
    def fahrenheit(self):
        return self._celsius * 9 / 5 + 32

t = Temperature(100)
print(t.fahrenheit)   # 212.0
t.celsius = 0
print(t.fahrenheit)   # 32.0
dica

Prefixe atributos "privados" com um sublinhado (_celsius) por convenção. O Python não impõe controle de acesso, mas o sublinhado sinaliza "não toque nisso diretamente".

@classmethod e @staticmethod​

class Date:
    def __init__(self, year, month, day):
        self.year, self.month, self.day = year, month, day

    @classmethod
    def from_string(cls, date_str):
        year, month, day = map(int, date_str.split("-"))
        return cls(year, month, day)   # cria uma instância

    @staticmethod
    def is_leap_year(year):
        return year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)

d = Date.from_string("2024-03-15")
print(Date.is_leap_year(2024))  # True
