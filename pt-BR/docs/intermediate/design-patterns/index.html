Padrões de Projeto em Python

Neste módulo você vai aprender como os padrões de projeto clássicos são expressos em Python idiomático. Padrões são soluções reutilizáveis e comprovadas para problemas recorrentes de design de software. As funções de primeira classe, decorators e tipagem dinâmica do Python frequentemente tornam os padrões mais concisos do que em outras linguagens. Ao final você será capaz de reconhecer e aplicar os padrões Factory, Singleton, Observer, Strategy e Iterator em código real.

Objetivos de Aprendizagem​

  • Entender por que os padrões de projeto importam e quando aplicá-los
  • Implementar o padrão Factory para desacoplar a criação de objetos
  • Usar o padrão Singleton para impor uma única instância
  • Aplicar o padrão Observer para comunicação orientada a eventos
  • Usar o padrão Strategy para trocar algoritmos em tempo de execução
  • Construir o padrão Iterator com __iter__ e __next__

Teoria​

Por que Padrões de Projeto?​

Padrões de projeto são plantas arquitetônicas. Eles não dizem o código exato para escrever — descrevem a estrutura de uma solução para que você possa adaptá-la ao seu problema. Aprendê-los permite que você:

  • Comunique intenção com outros desenvolvedores usando um vocabulário compartilhado
  • Evite reinventar soluções para problemas conhecidos
  • Escreva código mais fácil de estender e testar
nota

Em Python, muitos padrões clássicos (Command, Template Method, Strategy) podem ser simplificados com funções de primeira classe em vez de hierarquias de classes elaboradas. Padrões Pythônicos dependem de callables, closures e generators.

Padrão Factory​

Um Factory centraliza a criação de objetos, ocultando qual classe concreta é instanciada. Isso desacopla o código cliente dos detalhes de implementação:

class Dog:
    def speak(self): return "Woof!"

class Cat:
    def speak(self): return "Meow!"

class AnimalFactory:
    _registry = {"dog": Dog, "cat": Cat}

    @classmethod
    def create(cls, kind):
        animal_class = cls._registry.get(kind)
        if animal_class is None:
            raise ValueError(f"Unknown animal: {kind!r}")
        return animal_class()

animal = AnimalFactory.create("dog")
print(animal.speak())   # Woof!

Padrão Singleton​

Um Singleton garante que apenas uma instância de uma classe possa existir. Em Python, a abordagem mais limpa sobrescreve __new__:

class Config:
    _instance = None

    def __new__(cls, *args, **kwargs):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance.settings = {}
        return cls._instance

c1 = Config()
c2 = Config()
print(c1 is c2)   # True — mesmo objeto
dica

Singletons são úteis para objetos de configuração, logging ou pools de conexão — qualquer coisa onde exatamente uma instância compartilhada faz sentido. No entanto, podem dificultar o teste porque carregam estado global.

Padrão Observer​

O Observer (também chamado Publish/Subscribe ou sistema de eventos) permite que objetos se inscrevam em eventos publicados por outro objeto. O publicador não precisa saber quem está escutando:

class EventEmitter:
    def __init__(self):
        self._listeners = {}

    def on(self, event, callback):
        self._listeners.setdefault(event, []).append(callback)

    def emit(self, event, *args, **kwargs):
        for cb in self._listeners.get(event, []):
            cb(*args, **kwargs)

emitter = EventEmitter()
emitter.on("login", lambda user: print(f"{user} logged in"))
emitter.emit("login", "Alice")   # Alice logged in

Padrão Strategy​

O padrão Strategy define uma família de algoritmos e os torna intercambiáveis. Em Python, estratégias são frequentemente funções simples ou callables:

def bubble_sort(data):
    data = data[:]
    for i in range(len(data)):
        for j in range(len(data) - i - 1):
            if data[j] > data[j+1]:
                data[j], data[j+1] = data[j+1], data[j]
    return data

class Sorter:
    def __init__(self, strategy=sorted):
        self.strategy = strategy

    def sort(self, data):
        return self.strategy(data)

s = Sorter(strategy=bubble_sort)
print(s.sort([3, 1, 4, 1, 5]))   # [1, 1, 3, 4, 5]
dica

Quando uma estratégia pode ser expressa como uma única função, passe a função diretamente em vez de envolvê-la em uma classe. As funções de primeira classe do Python tornam esse padrão muito leve.

Padrão Iterator​

Um Iterator fornece acesso sequencial a elementos sem expor a estrutura de dados subjacente. Em Python, você implementa __iter__ e __next__:

class CountDown:
    def __init__(self, start):
        self.current = start

    def __iter__(self):
        return self

    def __next__(self):
        if self.current <= 0:
            raise StopIteration
        val = self.current
        self.current -= 1
        return val

for n in CountDown(3):
    print(n)   # 3, 2, 1

Como alternativa, use uma função generator com yield:

def count_down(start):
    while start > 0:
        yield start
        start -= 1
