REST APIs & HTTP

Neste módulo você vai aprender como aplicações web se comunicam via HTTP, como trabalhar com dados JSON, como usar os padrões da biblioteca requests para operações GET, POST, PUT e DELETE, e como lidar com autenticação e erros de API. Como chamadas HTTP reais não funcionam dentro do sandbox do navegador, os exercícios usam um objeto requests simulado que se comporta de forma idêntica à biblioteca real — então você aprende exatamente os mesmos padrões que usaria em produção.

Objetivos de Aprendizagem​

  • Entender os métodos HTTP: GET, POST, PUT, DELETE
  • Analisar e construir JSON com o módulo json do Python
  • Usar requests.get(), requests.post(), requests.put(), requests.delete()
  • Tratar erros HTTP e códigos de status
  • Passar cabeçalhos (como chaves de API, tokens Bearer)
  • Entender o design de recursos RESTful

Teoria​

Métodos HTTP​

APIs REST se comunicam via HTTP usando quatro métodos principais:

MétodoPropósitoTem Corpo?
GETRecuperar um recursoNão
POSTCriar um novo recursoSim
PUTSubstituir um recurso existenteSim
DELETERemover um recursoNão

Um recurso é identificado por uma URL como https://api.example.com/users/42. A resposta inclui um código de status:

CódigoSignificado
200OK
201Created
400Bad Request
401Unauthorized
404Not Found
500Internal Server Error

A Biblioteca requests​

A biblioteca requests é o cliente HTTP padrão do Python:

import requests

# GET
response = requests.get("https://api.example.com/users")
print(response.status_code)   # 200
data = response.json()        # parse JSON body

# POST
response = requests.post(
    "https://api.example.com/users",
    json={"name": "Alice", "email": "alice@example.com"}
)

# PUT
response = requests.put(
    "https://api.example.com/users/1",
    json={"name": "Alice Smith"}
)

# DELETE
response = requests.delete("https://api.example.com/users/1")

Cabeçalhos de Autenticação​

Muitas APIs exigem uma chave de API ou token Bearer no cabeçalho Authorization:

headers = {"Authorization": "Bearer my_secret_token"}
response = requests.get("https://api.example.com/protected", headers=headers)

Tratamento de Erros​

Sempre verifique o código de status ou use response.raise_for_status():

response = requests.get(url)
if response.status_code == 200:
    data = response.json()
elif response.status_code == 404:
    print("Resource not found")
else:
    response.raise_for_status()   # raises HTTPError for 4xx/5xx

Módulo JSON​

O módulo json embutido do Python converte entre objetos Python e strings JSON:

import json

# Python -> JSON string
data = {"name": "Alice", "scores": [95, 87]}
json_str = json.dumps(data, indent=2)

# JSON string -> Python
parsed = json.loads(json_str)
print(parsed["name"])   # Alice
