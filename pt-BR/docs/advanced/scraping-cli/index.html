Web Scraping & Ferramentas CLI

Neste módulo você vai aprender padrões de web scraping — extraindo dados estruturados de HTML — e como construir ferramentas de interface de linha de comando (CLI) com o módulo argparse do Python. Como o BeautifulSoup pode não estar disponível no sandbox do navegador sem o micropip, os exercícios de scraping usam strings HTML simuladas com regex e métodos de string (os mesmos padrões que você aplicaria em HTML real). Para os exercícios de CLI, você testa parsers argparse usando listas de argumentos explícitas.

Objetivos de Aprendizagem​

  • Analisar strings HTML usando métodos de string e re
  • Extrair dados com padrões semelhantes a seletores CSS
  • Entender a API do BeautifulSoup para uso no mundo real
  • Construir ferramentas CLI com argparse
  • Definir argumentos posicionais e opcionais
  • Testar CLIs com parse_args() em listas de argumentos explícitas

Teoria​

Estrutura HTML​

HTML é uma árvore de elementos (tags) que contêm texto e atributos:

<html>
  <body>
    <h1 class="title">Hello World</h1>
    <ul id="items">
      <li><a href="/page/1">Page 1</a></li>
      <li><a href="/page/2">Page 2</a></li>
    </ul>
  </body>
</html>

O web scraping extrai dados dessa estrutura de forma programática.

BeautifulSoup (Mundo Real)​

Em um ambiente Python real, você instalaria beautifulsoup4 e usaria:

from bs4 import BeautifulSoup

soup = BeautifulSoup(html_string, "html.parser")

# Find by tag
title = soup.find("h1").text              # "Hello World"

# Find all links
links = soup.find_all("a")
hrefs = [a["href"] for a in links]        # ["/page/1", "/page/2"]

# CSS selectors
items = soup.select("ul#items li a")      # all <a> inside the list

Análise com re (Compatível com Navegador)​

No sandbox do navegador usamos re para extrair dados de strings HTML:

import re

html = '<a href="/page/1">Page 1</a><a href="/page/2">Page 2</a>'

# Extract all href values
hrefs = re.findall(r'href="([^"]+)"', html)   # ['/page/1', '/page/2']

# Extract text between tags
texts = re.findall(r'<a[^>]*>([^<]+)</a>', html)  # ['Page 1', 'Page 2']
dica

re.findall(pattern, text) retorna uma lista de todas as correspondências. Se o padrão tiver um grupo de captura (...), retorna as strings capturadas. Com múltiplos grupos, retorna uma lista de tuplas.

Consulte re — Operações com expressões regulares.

argparse — Ferramentas CLI​

argparse é a biblioteca padrão do Python para construir interfaces de linha de comando:

import argparse

parser = argparse.ArgumentParser(description="My CLI tool")

# Positional argument (required)
parser.add_argument("filename", help="Input file path")

# Optional argument (flag)
parser.add_argument("--verbose", "-v", action="store_true", help="Verbose output")

# Optional argument with value
parser.add_argument("--output", "-o", default="output.txt", help="Output file")

# Numeric argument with type conversion
parser.add_argument("--count", type=int, default=10, help="Number of results")

Em produção, chame parser.parse_args() sem argumentos (lê sys.argv). Em testes, passe uma lista explícita:

args = parser.parse_args(["myfile.txt", "--verbose", "--count", "5"])
print(args.filename)   # "myfile.txt"
print(args.verbose)    # True
print(args.count)      # 5

Consulte argparse — Parser para opções de linha de comando.
