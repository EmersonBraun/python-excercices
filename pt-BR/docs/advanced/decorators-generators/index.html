Decorators & Generators

Neste módulo você vai dominar dois dos recursos mais poderosos do Python: decorators que envolvem e aprimoram funções sem modificá-las, e generators que produzem valores de forma preguiçosa para iteração eficiente em memória. Ao final você será capaz de escrever decorators reutilizáveis, criar sequências infinitas com yield e usar itertools para compor pipelines.

Objetivos de Aprendizagem​

  • Entender o padrão decorator e a sintaxe @
  • Escrever decorators com e sem argumentos
  • Usar functools.wraps para preservar metadados
  • Criar funções geradoras com yield
  • Escrever expressões geradoras
  • Combinar generators com itertools

Teoria​

Decorators​

Um decorator é uma função que recebe outra função como argumento, a envolve com comportamento adicional e retorna a versão modificada. A sintaxe @ é um atalho para func = decorator(func):

import functools

def shout(func):
    @functools.wraps(func)  # preserves __name__, __doc__, etc.
    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)
        return str(result).upper()
    return wrapper

@shout
def greet(name):
    return f"hello, {name}"

greet("alice")   # "HELLO, ALICE"
dica

Sempre aplique @functools.wraps(func) na sua função wrapper interna. Sem isso, a função decorada perde seu __name__ e __doc__ originais, o que prejudica a introspecção e a depuração.

Decorators com Argumentos​

Para passar argumentos a um decorator, adicione uma terceira camada — uma função fábrica que retorna o decorator real:

def repeat(n):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(n):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator

@repeat(3)
def say(msg):
    print(msg)

say("hi")   # prints "hi" three times

Decorators de Classe​

Classes também podem ser decorators se implementarem __call__:

class Counter:
    def __init__(self, func):
        functools.update_wrapper(self, func)
        self.func = func
        self.calls = 0

    def __call__(self, *args, **kwargs):
        self.calls += 1
        return self.func(*args, **kwargs)

@Counter
def add(a, b):
    return a + b

add(1, 2)
add(3, 4)
print(add.calls)   # 2

Consulte Decorators no glossário do Python.

Generators​

Uma função geradora usa yield em vez de return. Ao chamá-la, ela retorna um objeto gerador que produz valores um por vez — calculando cada valor apenas quando solicitado (avaliação preguiçosa):

def count_up(start, stop):
    n = start
    while n <= stop:
        yield n
        n += 1

for x in count_up(1, 5):
    print(x)   # 1, 2, 3, 4, 5

Generators são ideais para sequências grandes ou infinitas pois nunca armazenam todos os valores na memória ao mesmo tempo.

Expressões Geradoras​

Como list comprehensions, mas com () — criam um generator sem precisar definir uma função:

squares = (x**2 for x in range(1_000_000))   # no memory spike
total = sum(squares)

Fundamentos de itertools​

O módulo itertools fornece ferramentas combináveis para pipelines de generators:

FunçãoDescrição
itertools.count(start)Contador infinito
itertools.cycle(iterable)Repete o iterável para sempre
itertools.islice(gen, n)Obtém os primeiros n itens
itertools.takewhile(pred, gen)Produz enquanto o predicado for True
itertools.dropwhile(pred, gen)Pula enquanto o predicado for True
itertools.chain(*iters)Concatena iteráveis
import itertools

fib_under_100 = list(itertools.takewhile(lambda x: x < 100, fibonacci_gen()))
