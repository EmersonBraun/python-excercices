Loops & Iteração

Loops permitem repetir um bloco de código sem copiá-lo e colá-lo. Neste módulo você vai aprender os dois construtores de loop do Python — for e while — juntamente com as ferramentas que tornam a iteração mais expressiva: range(), enumerate(), break, continue e loops aninhados.

Objetivos de Aprendizagem​

  • Escrever loops for sobre sequências e objetos range()
  • Escrever loops while com condições de término corretas
  • Usar break para sair de um loop antecipadamente e continue para pular uma iteração
  • Usar enumerate() para iterar com um índice
  • Construir loops aninhados para problemas multidimensionais

Teoria​

Loops for​

Um loop for itera sobre qualquer iterável — uma lista, string, tupla, range, etc.:

fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)

for char in "Python":
    print(char)
dica

A variável do loop (fruit, char) é apenas uma variável comum. Você pode chamá-la de qualquer coisa, mas escolha um nome significativo.

range()​

range() gera uma sequência de inteiros sem armazená-los todos na memória:

range(5)          # 0, 1, 2, 3, 4
range(1, 6)       # 1, 2, 3, 4, 5
range(0, 10, 2)   # 0, 2, 4, 6, 8  (passo de 2)
range(10, 0, -1)  # 10, 9, ..., 1  (contagem regressiva)

Consulte range() na documentação.

Loops while​

Um loop while se repete enquanto sua condição for True:

count = 0
while count < 5:
    print(count)
    count += 1
nota

Certifique-se sempre de que a condição do loop eventualmente se tornará False, caso contrário você criará um loop infinito.

break e continue​

  • break — sai imediatamente do loop envolvente
  • continue — pula o restante da iteração atual e vai para a próxima
for n in range(10):
    if n == 5:
        break       # para quando n chega a 5
    if n % 2 == 0:
        continue    # pula números pares
    print(n)        # imprime 1, 3

Consulte break e continue no tutorial.

enumerate()​

Quando você precisa do índice e do valor durante um loop, use enumerate():

colors = ["red", "green", "blue"]
for i, color in enumerate(colors):
    print(f"{i}: {color}")
# 0: red
# 1: green
# 2: blue

# Começar a contar do 1:
for i, color in enumerate(colors, start=1):
    print(f"{i}. {color}")

Loops Aninhados​

Você pode colocar um loop dentro de outro. O loop interno completa todas as suas iterações para cada iteração do loop externo:

for row in range(3):
    for col in range(3):
        print(f"({row},{col})", end=" ")
    print()   # nova linha após cada linha
dica

Cuidado com o desempenho: se ambos os loops executam n vezes, o corpo é executado n² vezes.

Consulte o Tutorial Python — Instruções for para mais informações.
