Dicionários, Conjuntos & Compreensões

Dicionários e conjuntos são os principais tipos de coleção não ordenada do Python. Dicionários mapeiam chaves para valores e estão presentes em todo código Python real. Conjuntos armazenam elementos únicos e suportam testes de pertencimento rápidos e operações matemáticas de conjuntos. Neste módulo você também dominará as compreensões de dicionário e conjunto para código conciso e expressivo.

Objetivos de Aprendizagem​

  • Criar, acessar e modificar dicionários
  • Usar métodos comuns de dicionário (.get(), .keys(), .values(), .items(), .update(), .pop())
  • Criar conjuntos e realizar operações de união, interseção e diferença
  • Escrever compreensões de dicionário e conjunto
  • Trabalhar com dicionários aninhados

Teoria​

Fundamentos de Dicionários​

Um dicionário é um mapeamento ordenado (Python 3.7+) de chaves únicas para valores, entre chaves:

person = {"name": "Alice", "age": 30, "city": "NYC"}
empty  = {}

Acesse valores pela chave. Chaves ausentes lançam KeyError — use .get() para fornecer um padrão:

person["name"]              # "Alice"
person.get("email")         # None    (chave ausente, sem erro)
person.get("email", "N/A")  # "N/A"  (padrão explícito)

Adicione, atualize e exclua entradas:

person["email"] = "alice@example.com"   # adicionar
person["age"] = 31                       # atualizar
del person["city"]                       # excluir
popped = person.pop("email")             # remover e retornar

Métodos de Dicionário​

d = {"a": 1, "b": 2, "c": 3}

d.keys()           # dict_keys(["a", "b", "c"])
d.values()         # dict_values([1, 2, 3])
d.items()          # dict_items([("a", 1), ("b", 2), ("c", 3)])

d.update({"d": 4, "a": 10})  # mescla outro dict (sobrescreve chaves existentes)
d.setdefault("e", 0)          # insere chave com padrão se não presente

# Iterar:
for key, value in d.items():
    print(f"{key} -> {value}")

Compreensões de Dicionário​

squares = {x: x**2 for x in range(1, 6)}
# {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Filtrar com condição:
even_squares = {x: x**2 for x in range(10) if x % 2 == 0}

# Inverter um dicionário:
original = {"a": 1, "b": 2, "c": 3}
inverted = {v: k for k, v in original.items()}
# {1: "a", 2: "b", 3: "c"}

Fundamentos de Conjuntos​

Um conjunto é uma coleção não ordenada de itens únicos, também entre chaves:

fruits = {"apple", "banana", "cherry", "apple"}  # "apple" armazenado uma vez
empty_set = set()   # NÃO {} — isso cria um dict vazio!
fruits.add("mango")         # adicionar um elemento
fruits.remove("banana")     # remover (lança KeyError se ausente)
fruits.discard("banana")    # remover (sem erro se ausente)
"cherry" in fruits          # True — teste de pertencimento O(1)
dica

Use um conjunto em vez de uma lista sempre que precisar de testes de pertencimento rápidos (in) ou precisar garantir unicidade.

Operações com Conjuntos​

a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

a | b   # união           {1, 2, 3, 4, 5, 6}
a & b   # interseção      {3, 4}
a - b   # diferença       {1, 2}  (em a mas não em b)
a ^ b   # diferença simét {1, 2, 5, 6}  (em um mas não em ambos)
a <= b  # verificação de subconjunto

Consulte Conjuntos na documentação.

Compreensões de Conjunto​

unique_lengths = {len(word) for word in ["cat", "dog", "elephant", "ox"]}
# {2, 3, 8}

Dicionários Aninhados​

Dicionários podem conter outros dicionários como valores:

database = {
    "alice": {"age": 30, "role": "admin"},
    "bob":   {"age": 25, "role": "user"},
}
database["alice"]["role"]   # "admin"
